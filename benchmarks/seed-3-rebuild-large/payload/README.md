# Ledger Workspace

This workspace is a clean restart after a larger MVP of `ledger`, a local personal expense tracker split into three packages: a pure core library, an HTTP JSON API server, and a CLI client that talks to the server.

The MVP accumulated strong opinions — about money, dates, API contracts, imports, and security posture — and they are all recorded as routed truth. Start from `AGENTS.md` and follow the loader; expect more routes than any single step needs, and load selectively.
