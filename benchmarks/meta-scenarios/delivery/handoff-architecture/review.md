# Meta-Scenario Review

## Routing And Selection

- The implementation request selects the Implementation workflow and its required skill first.
- The worker finds the concrete technical gap without reopening the accepted product Memory.
- Architecture is recommended once as helpful prior work, not imposed as a prerequisite, gate, or waterfall.

## Workflow Handoff

- After user accord, the Architecture workflow and its required skill govern only the bounded technical gap.
- Accepted technical direction is recorded without being confused with the already accepted product direction.
- Work returns coherently to Implementation after architecture acceptance; the workflows are not treated as parallel primaries.

## Trace Evidence

- Check workflow selection, required-route reads, recommendation wording, user accord, and the return to implementation directly in sequence.
- Flag a post-hoc claim of a handoff when the trace instead shows mandatory staging or product re-discovery.
