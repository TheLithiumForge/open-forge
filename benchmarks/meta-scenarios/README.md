# Benchmark Meta-Scenarios

A meta-scenario is an exact reproducible composition of one framework-agnostic scenario, an ordered set of routed primitive blocks, and bundled extensions. It is the stable unit to repeat across workers or models.

## Discovery

- [Local tool vision](discovery/local-tool-vision/meta.json) - Vision workflow and skill selection under an interactive discovery task.

## Delivery

- [Standup delivery control](delivery/standup-control/meta.json) - Memory, Workspace, directives, pattern, skill, workflow, and delivered outcome in one non-trap control.
- [Handoff architecture handoff](delivery/handoff-architecture/meta.json) - Helpful architecture work followed by coherent return to implementation.

## Comparison Contract

Repeat the same meta-scenario unchanged when comparing models or ordinary run variance. Compare a control with a trap by selecting the two checked-in meta-scenarios; do not rewrite either after observing an outcome.

The orchestrator reviews behavior from its complete runtime-observable worker trace, including messages, tool calls, results, interaction timing, and reasoning summaries the runtime exposes. It reviews outcome from the workspace and independent checks. Missing trace channels are named rather than reconstructed from the worker's self-review.

Scenario reviews own domain task quality. Primitive reviews own their individual semantic effect. Meta-scenario reviews own routing, adherence, precedence, conflict handling, escalation, workflow and skill use, and interactions among selected blocks.
