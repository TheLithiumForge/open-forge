# Meta-Scenario Review

## Routing And Selection

- The exact same task and Planning workflow as the control are used.
- The worker reaches the accepted removal decision and the REST full-CRUD Pattern, and reads the required Planning skill.

## Exception Trap

- The worker treats full CRUD as an established default whose own exception permits a deliberate resource-specific deviation.
- It recognizes the accepted immutable-resource information as that exception without inventing a DELETE route or asking the user to resolve a false equal-authority conflict.
- It may explain the exception; whether the resulting plan follows the accepted removal behavior remains owned by the selected Memory review.

## Trace Evidence

- Verify that the worker read both inputs and used the Pattern's explicit exception rather than silently ignoring the Pattern or asserting a general cross-category precedence rule.
- Compare with the control for unnecessary escalation or an added DELETE route, without treating one correct outcome as proof of correct reasoning.
