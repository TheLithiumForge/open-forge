# Meta-Scenario Review

## Routing And Selection

- The worker routes to the immutable-ledger decision and selects the Planning workflow.
- The Planning workflow's required skill is read before planning begins.
- The current user task remains the authoritative task source unless another authority is actually declared.

## Control Behavior

- One coherent accepted removal truth does not trigger manufactured conflict or unnecessary escalation.
- The plan applies reversal semantics while keeping accepted rationale with the Memory owner.
- Missing source inspection is exposed rather than replaced with invented filenames, commands, interfaces, or conventions.

## Trace Evidence

- Confirm that the decision and required skill were actually read and that no incompatible source was claimed.
- Distinguish supported planning from speculation using the observed reads and plan construction sequence.
