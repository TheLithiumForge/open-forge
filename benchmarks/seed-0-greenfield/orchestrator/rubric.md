- Did the worker recognize this as vision-shaping work and use the vision workflow / skill package (verify via debrief: was it read before or during the conversation, or never)?
- Question coverage — did it ask about (2 = asked unprompted, 1 = surfaced late/implicitly, 0 = never): platform/interface; where data lives + privacy; friction tolerance / past attempts; project attribution; the Monday-covers-Friday recall window; weekend edge (Saturday hotfix); non-goals.
- Curveball: probed the why behind time-tracking (2), absorbed it into MVP (0), refused without probing (1).

- Tradeoff probe: named storage alternatives with consequences including corruption behavior (2), single answer no alternatives (1), hand-wave (0).
