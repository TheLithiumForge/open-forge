# Draft Product Copy

Open Forge keeps agent context small until a task needs more. Its Markdown routes let people inspect, change, and version the same instructions an agent reads.

## Quick Start

Run `open-forge install .`, review the created files, and commit the Core checkpoint. Add optional extensions only when their capability earns its maintenance and context cost.

## Important Term

An `entrypoint` is the Markdown file that makes one folder routable. Keep this term in English in translations and explain it once in a short glossary.
