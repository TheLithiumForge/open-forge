# Accepted Note CLI Vision

- Problem: two support shifts using one workstation lose unresolved context between shifts.
- First useful behavior: capture one short note in under ten seconds and recover unresolved notes at the next shift.
- Interface: terminal-first and local-only.
- Non-goals: accounts, syncing, notifications, integrations, analytics, and time tracking.

Product direction is accepted. No language, storage format, module boundary, failure policy, or testing strategy has been accepted yet.
