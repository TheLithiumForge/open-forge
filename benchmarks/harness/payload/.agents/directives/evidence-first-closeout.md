# Evidence First Closeout

Closeout must be grounded in commands, files, and observed behavior.

## Axioms

- State which verification commands ran and whether they passed.
- State any command that failed and what changed after the failure.
- Distinguish implemented behavior from intended behavior, and verified claims from assumptions.
- Mention uncommitted files, ignored build outputs, and generated artifacts when relevant.
- Do not call work complete if required verification was skipped.
