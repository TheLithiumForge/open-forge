# Worker Vision Workflow

Worker vision turns a rough user idea into recorded direction that a cold future session can build from.

## Mode

iterative

## Goal

- outcome: an accepted direction - problem, core value, MVP boundary, non-goals, growth directions - recorded in routed memory
- acceptance: the user explicitly accepts, revises, defers, or rejects the direction, and accepted material is written where a cold session finds it
- stop: the user accepts, defers, or rejects

## Required Routes

none - the loader chain carries what this workflow needs.

## Constraints

- Treat direction as candidate until the user accepts it; ask for explicit confirmation before writing accepted truth to crystallized memory.
- Route candidate ideas and future directions to emerging ideas, never into accepted records.
- Prefer concise questions and concrete options over broad strategy prose.

## Steps

1. Clarify the problem, audience, desired outcome, constraints, and non-goals; ask rather than assume.
2. Identify the core value that must exist for the direction to matter.
3. Shape the MVP boundary and separate later growth directions explicitly.
4. Check fit, risks, and assumptions that could invalidate the direction.
5. Ask the user to accept, revise, defer, or reject the direction.
6. On acceptance, confirm promotion, then write the accepted record to crystallized memory, candidate ideas to emerging ideas, decisions with their rationale to decisions, and a session or handoff for cold continuation.

## Loop

Repeat steps 1 through 5 when answers change the audience, core value, boundary, constraints, or risks. Stop per the Goal's stop condition.

## Outputs

- accepted or candidate direction record
- MVP boundary and explicit non-goals
- routed candidate ideas and decisions with rationale
- session or handoff for cold continuation

## Completion

- [ ] explicit user decision obtained
- [ ] accepted truth written only after confirmed promotion
- [ ] candidate ideas routed to emerging ideas; decisions recorded with rationale
- [ ] a session or handoff exists that a cold session can resume from
- [ ] final response names this workflow
