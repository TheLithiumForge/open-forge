# Standup Journal Workspace

This workspace is a clean restart after a medium-sized MVP of `standup`, a work-journal CLI for remembering what you did between standups. The MVP taught hard lessons — especially about dates and storage — and those learnings are recorded as routed truth.

Start from `AGENTS.md` and follow the loader. The vision, accepted decisions, prior analyses, and expected patterns are all routed; nothing important lives only in this file.
