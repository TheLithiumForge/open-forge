# Project Target

The implementation target is `bookmarks/` at the workspace root.

`bookmarks/` should contain the CLI project, including source, tests, package metadata, and project README.

Use this route when creating, reviewing, or verifying the bookmarks CLI implementation.

Do not place implementation source directly in the workspace root.
