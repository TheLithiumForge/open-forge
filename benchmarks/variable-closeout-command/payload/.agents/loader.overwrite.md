# Loader Additions

The closeout recheck is one command in this workspace: before ending meaningful work, run `open-forge find --tag KeepInMind --bodies` from the workspace root. It prints every standing-follow-up route in one call so nothing needs to be remembered or re-found by hand. The obligation itself is unchanged: recheck loaded #KeepInMind entries and perform the follow-ups they require; the command only makes that cheaper than skipping it.
