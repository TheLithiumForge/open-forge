# Loader Additions

The continuity recheck is one command in this workspace: at task entry or resume, context restoration, meaningful phase transitions or handoffs, and closeout, run `open-forge find --tag KeepInMind --bodies` from the workspace root. It prints the complete routed standing-follow-up catalogue in one call. Every result is binding follow-up context within its owning authority; the command makes complete recovery cheaper than omission.
