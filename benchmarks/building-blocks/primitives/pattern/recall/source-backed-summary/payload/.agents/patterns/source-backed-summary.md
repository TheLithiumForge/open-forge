# Source-Backed Summary

Use this pattern when a concise answer must carry existing project truth into later work.

## Shape

1. Name the authoritative source or sources used.
2. Separate accepted constraints, explicit non-goals, and required verification.
3. Keep each material claim traceable to its owner without copying the complete source.
4. End with search, availability, or evidence limitations that narrow confidence.

## Review Checks

- Accepted facts are not blended with inference or convenience guidance.
- Important constraints and checks are not lost through over-compression.
- The summary remains shorter and easier to use than the source material it points to.
