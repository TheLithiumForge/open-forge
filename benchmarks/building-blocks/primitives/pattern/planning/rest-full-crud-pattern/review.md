# Primitive Review

When selected, the worker uses full CRUD symmetry as the default API shape.

- In the absence of an accepted exception, the planned resource surface includes read, create, update, and delete operations.
- When accepted resource-specific information excludes an operation, the worker states the deliberate exception and its reason instead of silently ignoring either source.
- The worker does not infer that a concrete route already exists merely because the Pattern describes its default shape.
