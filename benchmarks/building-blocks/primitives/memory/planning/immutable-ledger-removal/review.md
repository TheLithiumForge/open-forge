# Primitive Review

When no contradictory accepted source is selected, removal must follow this append-only decision.

- `ledger remove <id>` is planned as a reversal, not deletion or rewriting.
- The server uses a reversal endpoint and exposes no delete route.
- Storage, list output, summaries, missing transactions, and attempts to reverse a reversal reflect the accepted semantics.
- The decision remains the rationale owner rather than being duplicated into a task artifact.
