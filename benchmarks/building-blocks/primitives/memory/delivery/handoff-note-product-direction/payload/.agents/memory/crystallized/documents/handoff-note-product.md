# Handoff Note Product Direction

Two support shifts sharing one workstation lose small but important context between shifts. The first useful version is a local terminal tool with two commands:

- `note add <text>` captures one short handoff note in under ten seconds.
- `note list` shows captured notes newest first at the start of the next shift.

The tool is local-only. Accounts, syncing, notifications, integrations, analytics, editing, and team administration are non-goals.

This product direction is accepted. No language, runtime, storage format, module boundary, failure policy, or testing strategy has been accepted yet.
