# Memory Templates

Memory templates help preserve state and reasoning in the route that matches its current role.

## Axioms

- Choose the destination Memory state from the information's present meaning, not from the template's location
- Select a template by the primary question the record must preserve and its present lifecycle role, not by desired permanence
- Apply the destination state's inherited Axioms after instantiation; this route provides no alternate lifecycle or authority
- Replace template metadata, placeholders, and prompts with accurate source, scope, uncertainty, freshness, and relationships
- Search for an existing owner before creating another record, then extend, consolidate, or link it when appropriate
- Keep only information whose expected future value justifies its discovery and review cost
