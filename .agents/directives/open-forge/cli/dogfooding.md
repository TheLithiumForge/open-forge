# CLI Dogfooding Evidence

## Instructions

- Treat creation and use of the replacement Open Forge CLI as Framework dogfooding. Observe whether routing, task capsules, architecture packets, delegation, ownership continuity, phase boundaries, review budgets, generated projections, tests, and verification help or hinder the work.
- Record an operational occurrence when it changes the current task, causes rework, blocks an agent, repeats a known failure, crosses authority, exposes missing safety, or materially affects time, context, or quality.
- Aggregate routine recurrences by failure class, role, task profile, and consequence instead of writing one prose record per invocation. Preserve representative examples, counts when available, recovery, and the smallest promotion signal.
- Useful classes include start or completion failure, repeated tool failure, step or context truncation, duplicated exploration, overlapping ownership, scope drift, unexpected structure, omitted integration, avoidable review, false-positive review, stale evidence, maintainer correction, and primary-owner takeover.
- Keep immediate detail in the active task or checkpoint. Create or extend a matching Emerging Observation only when the evidence may prevent future cost, refine a reusable agent or workflow, or justify a tool or Framework change.
- For reusable observations, record expected behavior, observed behavior, consequence, recovery, alternatives, tradeoffs, recurrence, and what evidence would justify promotion or rejection.
- Preserve first-pass independence. Compare new review or council results with prior observations only after the independent return.
- Do not record provider, model, runtime profile, session, hidden orchestration, personal, machine, secret, token, local absolute-path, or incidental environment identifiers. Use normalized role names, repository-relative paths, and behavior-level evidence.
- Recurrence does not silently change Framework authority. Promote only the smallest supported change after the evidence and maintainer acceptance justify it.
