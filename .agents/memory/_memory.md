# Memory

Optional. Each folder below is optional on its own, so leave out the ones you do not want. Nothing outside Memory depends on it.

## Axioms

- Use an existing record before creating another, and say where a record came from and how certain it is when that affects trust.
- Saving or moving a record does not make it accepted. When a record's state changes, move it and leave no stale copy.
- Do not recreate a Memory folder that has been removed.
