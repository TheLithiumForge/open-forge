# Open Forge Cleanup Memory

This folder is a temporary extracted memory area for this repository before formal Open Forge dogfooding.

Use these files instead of the old session and idea files for current continuation:

- `current-state.md` - current repository state, source-of-truth files, and implementation status
- `decisions.md` - accepted design decisions extracted from sessions and idea notes
- `backlog.md` - pending priorities and deferred ideas still worth carrying forward
- `archive-map.md` - where old notes were moved and how to treat them

The archived session and idea files are historical context. Load them only when reconstruction is needed.
