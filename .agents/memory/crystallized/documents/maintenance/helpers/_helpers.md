# Maintenance Helpers

These helpers make repository authoring, review, and migration more consistent. They are not shipped Framework concepts or vocabulary that users must learn.

## Axioms

- Use the helpers while changing current Open Forge documents, runtime files, Templates, or public documentation
- Keep shipped and public material self-explanatory through direct natural language rather than referring readers to these helpers
- Update a helper when accepted terminology or knowledge-role boundaries change
