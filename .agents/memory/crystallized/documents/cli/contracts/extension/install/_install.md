# extension install Command

## Status And Authority

This entrypoint routes the accepted current Crystallized Interface and Behavior
contracts for `open-forge extension install`. The new CLI does not ship yet.
Install establishes managed ownership for selected absent package IDs and
verifies exact managed no-ops. Managed divergence directs to `extension update`.

- [`behavior.md`](behavior.md) defines source-universe and dependency resolution,
  Framework-anchor and route-host prerequisites, planning, ownership,
  fingerprints, generated navigation, recovery, and typed results.
- No Technical Design file exists. The accepted CLI Architecture defines the
  shared implementation boundary. Gate 5 must prove source-generated YamlDotNet
  and STJ serialization, fixed Markdig where used, real `System.IO`, Native AOT,
  OS locking, isolated tests, and package journeys. This contract does not claim
  that implementation or proof.
