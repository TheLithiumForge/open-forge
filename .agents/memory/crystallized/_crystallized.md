# Crystallized Memory

This folder holds accepted knowledge and decisions that should stay current within their scope.

## Axioms

- Check these Entries before deciding that no accepted knowledge applies.
- Keep only accepted current knowledge here, under the loader's acceptance rule and within each record's scope. Tags, repetition and agent confidence do not establish acceptance.
- When accepted direction changes a subject, update, split, merge or reshape its record instead of adding a competing current version.
- Archive or link material that is no longer current, and keep enough context to understand the change.
