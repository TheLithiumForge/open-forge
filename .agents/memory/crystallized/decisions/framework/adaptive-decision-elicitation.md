# Adaptive Decision Elicitation

## Context

Open Forge already distinguishes user authority, agent autonomy, routed context, optional Workflows, current documents, Decisions, #Core material, and Memory states.

The missing default was the interaction between sparse natural intent and those mechanisms. Technical users often supply enough design direction themselves. Less technical users may not know which choices matter and should not be expected to invent implementation structure or operate the Framework taxonomy.

A universal questionnaire or mandatory discovery phase would repeat the process overhead Open Forge exists to avoid.

## Decision

The base Framework requires agents to build the best current model from the request and accepted context before consequential work depends on an unsettled choice.

Agents match explanation and planning depth to the request's demonstrated expertise and desired fidelity. Unless deep analysis is requested, the first response remains conversational: current understanding, one coherent recommendation, and at most one material decision frontier. Deeper rationale, alternatives, architecture, or plans are offered before being supplied automatically. Agents surface only missing decisions that could materially change the outcome, scope, experience, structure, risk, cost, or verification. They distinguish recommendations from accepted direction and ask only for judgment the user must supply.

Reversible assumptions may remain visible and #Contextual when work can safely proceed. Settled direction is not reconfirmed, exhaustive specifications are not required, and low-impact preferences do not become gates.

Once direction is sufficient, agents continue through coherent in-scope work until completion or a material decision, conflict, uncertainty, or authority boundary requires user input. Routine execution does not stop merely to request another `continue` message.

Users express intent naturally. Agents select applicable `routes`, Workflows, Skills, Templates, and durable destinations. When an optional capability materially changes the interaction, the agent explains the useful approach in one natural sentence without requiring Framework vocabulary.

When material becomes accepted, agents identify the question each part answers, where it applies, and its expected lifetime without asking users to operate the Framework taxonomy. They create durable artifacts only when meaning should survive the task, then update every authoritative source that expresses distinct current meaning, rationale, mandatory behavior, or reusable shape. Durable outcomes, temporary continuation state, and unsettled reusable findings are reconciled before closeout.

After broad, consequential, difficult-to-reverse work or changes spanning several durable knowledge roles, agents consider whether an independent review could materially reduce omissions, excessive promotion, duplication, contradiction, or risk. The offer explains the review focus and additional model tokens, then asks before running unless standing direction already authorizes the expense. When context isolation is unavailable, the check is described as an adversarial second pass rather than an independent review.

Detailed Vision, Architecture, Planning, Development, Review, and Experience Design methods remain optional. They never form a mandatory lifecycle.

## Rationale

This preserves user authority where contextual judgment matters while reducing the expertise and ceremony required to provide useful direction.

Recommendations are more helpful than unbounded option lists. Outcome-oriented questions let users decide what they uniquely know without outsourcing technical design back to them.

The universal behavior belongs in the loader because it must apply before optional capabilities are selected. The richer adaptive method belongs in Guidance because it informs recurring contextual judgment without imposing a mandatory Workflow. Detailed methods remain optional because the shared Framework should not impose a development methodology.

Acceptance, durability, and reuse answer different questions. Applying those questions to accepted material prevents both missed extraction and the promotion of temporary structure into lasting knowledge. Independent review adds a fresh perspective without making its token cost mandatory for routine work.

## Alternatives And Tradeoffs

- Native agent competence alone would keep the base smaller but leave proactive elicitation inconsistent across agents and runtimes.
- A required discovery Workflow would improve consistency but impose stages and ceremony even when accepted context is sufficient.
- A universal questionnaire would make coverage visible but increase burden, encourage irrelevant answers, and perform poorly across different subjects and user expertise.
- Automatic inference without visible assumptions would reduce questions but let agent guesses become silent product direction.
- Requiring users to classify accepted material or approve routine destinations would expose Framework mechanics and recreate the ceremony Open Forge exists to remove.
- Running an independent review after every change would improve coverage but impose unnecessary model cost and delay on routine work.

The baseline contract adds repeated context cost. Its wording therefore remains compact and defines decision economy rather than a complete elicitation method.

## Consequences

- Natural conversation is sufficient input for ordinary Open Forge use.
- Agents adapt question depth to request completeness and material uncertainty.
- Agents adapt technical detail and planning depth to demonstrated expertise and requested fidelity.
- First responses remain conversational unless the user requested deep analysis, with deeper optional detail offered progressively.
- Technical users are not forced through settled questions.
- Less technical users receive recommendations and understandable decision points.
- Documents and other routed material emerge as warranted outcomes rather than required forms.
- Accepted material is integrated by question, scope, and expected lifetime without requiring users to supervise document classification.
- Small changes produce no new durable knowledge artifact when nothing needs to survive the task.
- Meaningful independent review is offered proportionately, states its additional cost, and remains user-controlled unless standing direction says otherwise.
- Evaluation must test consequential decision coverage, unnecessary questioning, safe continuation, temporary accepted state, warranted multi-role extraction, excessive promotion, stale candidate cleanup, and proportionate review offers.
