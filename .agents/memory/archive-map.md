# Archive Map

The old `.agents/sessions/` and `.agents/ideas/` files were archived during cleanup on 2026-07-06.

The useful current material was extracted into:

- `current-state.md`
- `decisions.md`
- `backlog.md`

## Archived Locations

- Old sessions: `.agents/archive/sessions/`
- Old idea notes: `.agents/archive/ideas/`

## How To Use The Archive

- Treat archived files as historical context, not active truth.
- Prefer the extracted memory files for continuation.
- Load archived sessions only when reconstructing original intent or old rationale.
- Load archived ideas only when a deferred design needs its detailed reasoning.
- If archived material conflicts with current source files or extracted decisions, current source files and extracted decisions win unless the user chooses to restore or revise history.

## Archived Because

- The old session files mixed current direction, old structures, superseded paths, and raw discussion history.
- The old idea files were useful while designing, but most current decisions now live in maintained framework docs or installable payload files.
- Keeping the raw files active made agents pay context cost for historical baggage.
