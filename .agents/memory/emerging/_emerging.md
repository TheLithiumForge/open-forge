# Emerging Memory

## What is useful but still unsettled?

This folder holds useful ideas, findings and reasoning that are not accepted yet.

## Axioms

- At each #KeepInMind refresh, check these Entries and save useful candidate material before it is lost. "Nothing useful to save" is a valid result. Do not turn raw activity into Memory.
- Keep each record's source, uncertainty and scope visible when they affect later use.
- Refine material while its validity, use or final destination is unsettled.
- When something is accepted, move the durable result to the source that should define it. Before moving or pruning rejected or replaced material, keep its useful outcomes and reasoning.
- Revisit repeated or stale material and decide whether to consolidate, promote, move or prune it.
