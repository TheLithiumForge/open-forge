# Reference Propagation Probe

## Question

Can an agent with no conversation history enter Open Forge through the workspace contract, discover every current source affected by a small terminology change, update live references without rewriting historical records, and validate the result?

## Method

The probe used a detached worktree at commit `6460aa7`.

Before delegation, the evaluating agent privately mapped the files and references expected to change. A fresh agent received only the isolated workspace and this accepted experimental direction:

- Replace `selection surface` and `routing surface` with the clearer `route description`
- Keep `routed body` for content opened through a selected route
- Update current material, installable source, affected names, links, generated representations, and validation
- Preserve archived and historical wording

The prompt did not name affected files or provide this expected set.

## Result

The agent entered through the workspace contract and found every privately expected current definition, source and dogfood copy, maintenance relationship, Decision backlink, and generated entry. It also found legitimate secondary uses in Patterns, Workflows, overwrite semantics, and active migration context.

The agent renamed the affected Decision and updated every live link. Historical wording remained unchanged; one archived link destination changed only because the referenced current file moved. A targeted search found no stale nonhistorical term or link.

The first writing review found terminology drift, punctuation defects, one ambiguous sentence, one incorrect applicability relationship, and one misleading description of route-description size. The agent corrected those findings, reran the affected review, and reached a clean result. The independent semantic-loss review found no material loss.

The agent reported successful index rebuilding, `open-forge doctor` at the repository root and installable source root, `git diff --check`, the 25-test focused suite, build, and `bun run test:ci` with 151 passing tests.

## Conclusions

This probe supports the following contextual conclusions:

- The loader, routed current documents, Maintenance relationships, ordinary links, generated indexes, and repository search can compose into a complete maintenance path for a cross-cutting terminology change
- Links make relationships explicit and correctable, while search catches related wording that has no direct dependency edge
- The Framework made complete propagation likely and reviewable in this case; it did not turn semantic synchronization into a deterministic guarantee
- Independent writing review added material value even after the agent found the complete file surface
- The 151-test `bun run test:ci` suite was more validation than this Markdown-only experiment needed; future review should apply the existing proportional-verification rule more deliberately

For duplicated knowledge, one source should contain the complete current rule. Another independently useful entry point may repeat the minimum meaning required to act correctly, then link to the complete source. Repeating a full rule across current documents still creates synchronization and review cost even when Git, links, routing, and search make that cost manageable.

The current [Open Forge Writing Standard](../../crystallized/documents/maintenance/writing.md) is authoritative for voice and prose quality. The [Canonical Markdown Syntax](../../crystallized/documents/framework/markdown/syntax.md) is authoritative for notation. The repository-only [Terminology Helper](../../crystallized/documents/maintenance/helpers/terminology.md) provides detailed maintainer vocabulary. Decisions preserve why those contracts were accepted rather than remaining parallel catalogues of current rules.

## Limits

This was one agent, one terminology change, one repository state, and one tool environment. It does not prove equal discovery or compliance across agents, models, runtimes, larger migrations, or relationships that are neither linked nor searchable by established terms.

The terminology change was an isolated probe and was not applied to the primary worktree.
