# Test Audit Council Reviews

Each member ranked the four proposals that weren't its own against six weighted goals: journeys covered, planted-bug failures kept, agent time, load sensitivity, the grader's regression signal and migration cost. Lightly condensed.

## Review by A

Ranking: D, C, B, E. D keeps every journey and every test failing on a planted bug, backs choices with mutants in reference-audit/mutation-results.json and leaves keyboard untouched; weakness is time, about 575s near the grader's 600s CandidateLimits.commandSeconds, so T07.5 can still time out under load. C best on load sensitivity (explicit timeouts, the per-file npm --version spawn, the clock-edges busy wait) but drops control-contract 'export keeps populated progress running and exposes a static imported win' (fails on B1) and saved-bests (only M40 catcher). B finds the P2 gap and cuts deeply but edits keyboard.e2e, forcing B2 and P1 regeneration, and drops play's keyboard game (fails on B2). E fastest at about 220s but drops status, status-controls and product-contract (B1's starting failures from 7 to about 3), play's edges test, rewrites keyboard.e2e and changes test:e2e, so migration costs most.

Steal: D, completion.test.ts pairs cards using the game's own state.deck, so it can't catch a wrong deal; the unit oracle covers only 4x4 (generateBoard(EXAMPLE_CODE)); every size's specDeal check should move into deck.test.ts (A's Stage 1 claim that sizes 6 to 14 repeat completion.test.ts was wrong). D, keep layout at 1280x1400, since board.css uses max-height min(70dvh, 768px) and only at 1400px tall does V03's cap apply. D, the mutants' recorded killers as the keep list: M22 (scrollbars 10x10 at 900x600), M23 (clock-edges 'export reads the active clock between render ticks'), M26 and M27 (idle-clock), M36 (pointer-focus at 640x400), M40 (saved-bests; session.test.ts starts from EMPTY_PREFERENCES). C with D's limit: explicit longer timeouts for accessibility (24s against 30s) and all-sizes at 16x16, and npm version from npm_config_user_agent instead of a spawn per file, keeping the suite well under 600s. B, close the P2 gap: the first-reveal test clicks card 2 again but never reveals a different card.

Most dangerous: trimming keyboard.e2e.test.ts (B and E). B2's seed.patch deletes that exact file and solution.patch restores it, so any edit forces regenerating B2 and P1. In E play's edges test also goes, so the agent's own run can't catch a B2 fix that wraps at edges or takes over modifier keys; only hidden I06 and I07 checks would, so B2 gets harder and stops being comparable with earlier runs.

Revised: all-sizes trims to size 16 with a 90s timeout, moving the example-deck test and a per-size specDeal check into deck.test.ts. layout keeps all three views. saved-bests trims to the 10-move import test (M40, R5). idle-clock keeps (M26, M27). clock-edges drops only 'a capped imported clock keeps matching, closing and exporting valid progress', keeps the export test (M23). scrollbars keeps 16x16 at 1280x800 and 10x10 at 900x600 (M22). pointer-focus keeps clicks at 360x800, 1280x800 and 640x400 (M36) and taps at 360x800. accessibility keeps with a 60s timeout. game.test.ts extends the first test with the different-card reveal. About 71 browser tests in 29 files, about 510s under the 2026-11-03 load or about 130s on an idle verifier; the npm --version fix keeps a margin under 600s. Planted-bug failures stay 2 unit plus 7 browser for B1, 12 browser for B2, 1 for B3, 1 plus 1 for B4.

A is the only one counting seed failures from validation.json, keeps every test failing on a planted bug and the keyboard files byte-identical; it still drops idle-clock (only catch for M26, M27), clock-edges' export test (M23), the 900x600 scrollbar view (M22), saved-bests (M40) and spacing's 1280 view, though max-width 599px media queries make the two views differ. C strongest on load-sensitive tests, its claim confirmed in use-session-clock.ts (the mismatch closes on a 40ms tick, so once a Playwright round trip exceeds 800ms the overdue test passes without testing the overdue path); it drops control-contract test 3 (fails on B1) and the 1280x1400 layout view (fails on B2, only check of V03's 768px cap). B finds a real P2 gap but cuts tests failing on B2 (play's keyboard game, status-controls' phone test), trims keyboard so the B2 seed must be rebuilt, drops clock-edges and admits a broken clock.synchronize() would then pass. E loses the most: tests failing on B1 (status, status-controls, product-contract), all clock wiring, a changed test:e2e command, every seed regenerated, and focus-entry's outline test moved into keyboard.e2e.test.ts, which B2's seed deletes.

Steal: C, run the overdue-mismatch check against fractional-clock's stubbed performance.now inside one evaluate instead of the 800ms busy wait. C, read the npm version from npm_config_user_agent instead of spawning npm per file. C, wait for several equal frames in pointer-focus's wheelBoard as touch-scroll does, and give all-sizes and accessibility explicit timeouts above 30s. A, the seed-failure table as a pass gate for any cut (B1 2 unit plus 7 browser, B2 13, B3 1, B4 1 unit plus 1 browser). B, extend 'first reveal starts play without a move and ignores invalid activation' to reveal a different card and assert one move.

Revised: snapshots keeps both tests ('invalid drafts keep the current game and a loaded win changes neither best nor celebration' fails at B1's start: Expected "none", Received "0"). status-controls keeps all three ('the best label uses one wording before and after a record exists' expects none, fails on B1). matched-mark trims to 16x16 at 360x800 (mark is 16% of the card, smallest card is strictest, keeps M34). clock-edges keeps, rewriting the overdue test with the stubbed clock. scrollbars drops 1440x800 (both 1440 and 1280 exceed the 1120px content cap, same board), keeps 900x600 for M22. game.test.ts extends for P2. About 77 browser tests; B1 keeps all 7 failing browser tests and B2 all 13.

About 33 browser tests and 270s; B1 still fails in storage plus 5 of 7 browser tests (the two dropped repeat the same assertion), B2 in about 10 of 13, B3 and B4 lose nothing.
