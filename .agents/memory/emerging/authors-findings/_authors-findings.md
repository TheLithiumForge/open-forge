# Authors' Findings

This route is a protected notebook for findings the maintainer wants to retain
without silently promoting them to accepted current truth.

## Lifecycle

- A finding is stated, observed, or inferred material whose future value is not
  yet settled.
- The route is retained by default. Do not archive, delete, consolidate,
  overwrite, or prune a finding without explicit maintainer direction.
- A finding does not become a Directive, Decision, CurrentTruth, or Task merely
  because it is recorded here.
- When a finding is accepted for execution, copy only the actionable result into
  the owning Task and link back here for provenance. The Task then owns changes
  discovered during implementation.
- New evidence that changes an open Task belongs in that Task or a new analysis
  record; do not rewrite a sealed analysis to follow implementation drift.
