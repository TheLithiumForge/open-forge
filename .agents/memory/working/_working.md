# Working Memory

Working Memory is temporary context for continuing or resuming active work.

## Axioms

### Use And Status

- Read `Entries` before deciding that no working memory applies.
- Use Working Memory to help work resume. Saving material here does not make it accepted.
- Working Memory may preserve an explicitly accepted temporary choice when its source, scope, and expected expiration are clear.

### Maintenance

- Keep Working Memory small, current, and easy to replace.
- When the active need ends, keep any useful result, then move, archive, consolidate, or prune the record.
