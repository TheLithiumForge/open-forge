[CLI Architecture Authority Audit](../../../emerging/analysis/2026-09-02_cli-architecture-authority-audit.md).

that would require choosing new meaning returns to the Overseer or maintainer
instead of being resolved as an editorial change.

current `.agents/directives/csharp/_csharp.md`, `design.md`, and `style.md`
files and report fresh SHA-256 fingerprints before acting. Documentation-only
work does not waive those rules when it judges C# architecture or design.
