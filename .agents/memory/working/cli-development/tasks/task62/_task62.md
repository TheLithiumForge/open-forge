# Task 62 execution packets

These packets execute the accepted outcome in [Task 62](../task62-glob-scoped-loading.md).
[Execution](execution.md) owns the frozen decisions, current phase, milestones,
integration state, and verification receipts. The plans below specify the edits.
They do not create a second acceptance or progress ledger.

## Axioms

- inherited - No local axioms; loaded ancestor axioms remain active.

## Dispatch rules

Before dispatch, read the selected packet and its prerequisites. Each worker
independently loads `AGENTS.md`, `.agents/loader.md`, relevant ancestor routes,
and the current complete C# Directives when authoring or reviewing C#.
The packet supplies scope and accepted meaning, not permission to skip context.

Each mutating worker has its own branch and worktree. Workers are not alone in
the repository. They preserve other changes and never revert another worker's
edits. Root alone copies dependency outputs and integrates completed changes.
No worker commits, merges, contacts remotes, or installs packages from a network.

The short slice identifiers in these plans refine the graph in Execution:
F4 separates the shared source evaluator from C1, and W1–W5 divide D1–D3 into
disjoint writing assignments. These are packet identifiers, not new Tasks.

| --- | --- | --- |

| 1 | F2 after F1 | Optional metadata facts survive every source projection, including missing metadata and Skills |

W1–W5 may draft concurrently with foundations. Their command examples remain
pending verification until the relevant command slice passes. Root serializes
generated Entries changes after prose integration. It does not assign multiple
workers the same entrypoint or snapshot file.

## Common receipt

Each worker returns exact changed and new paths, copied dependency identities,
commands and exit codes, selected tests and counts, meaningful output or byte
evidence, and remaining limitations. Record deviations in the assigned plan's
`Divergences observed` section through root if several workers share that plan.
Only root updates [Execution](execution.md), task state, and acceptance.

Stop and return a narrow change request if a frozen callable contract is absent,
the inspected code contradicts accepted meaning, an owned change needs a protected
surface, preservation cannot be proved, or a test requires changing the contract.
Do not invent a local substitute or weaken evidence to finish a slice.

## Main risks

| Risk | Required proof |
| --- | --- |
| Optional facts disappear behind required metadata state | Root-only and Skill `applyTo` remain visible to evaluation and Doctor |
| Different files satisfy different ancestors | One file must satisfy the whole chain before `Matched` is returned |
| Hidden ancestors activate through a global search | Context stays top-down while Find only filters its own result universe |
| Updates rewrite unrelated authored bytes | Exact before/after byte assertions for both declaration locations and unrelated fields |
| New defaults or wire fields change legacy commands | Status keeps its existing startup mode and unconditioned JSON omits optional applicability |
