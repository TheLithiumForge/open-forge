## Execution boundary

One coordinator owns architecture, shared files, exact dispatch, acceptance and
Git. Use Worker Watch directly, with all cooperating workers in this worktree
and one explicit shared-workspace group. Verify daemon capacity, enabled idle
slots and write permissions before dispatch. Scheduling permission is separate
from filesystem permission. Do not restart unrelated active work.

Use Luna/xhigh for literal inventories and frozen documentation substitutions;
use Luna/max for the specified semantic changes and evidence. Three independent
investigations were sufficient here; two ran through Worker Watch and the
coordinator reproduced navigation locally. Do not create filler work to reach
a worker count. Runtime identities and raw evidence remain in ignored local
receipts, not in these repository documents.

Every worker prompt must say: other agents share the tree; preserve their
changes; write only the listed files and your reserved receipt; perform no Git
actions; do not expand scope or guess a contract; return unexpected dependencies
to the coordinator. Load the applicable repository context independently.
C# authors and reviewers must read the complete current C# directive entrypoint,
design and style files. Documentation workers read the writing standard and
dictionary. These are semantic tasks, not the mechanical context exception.

## Ordering and shared ownership

The current partition has six documentation workers over 28 disjoint existing
files, one Extension failure-fact worker followed by one connected output worker,
and sequential Doctor identity/advice/evidence work. Documentation may run beside
the first code slice. Later command-family error lanes remain explicitly withheld
until their producer mappings and exact expected output are frozen. This is
intentional staging, not a claim that the entire 19-command sweep is ready.

1. Accept the evidence and proposed outcome of each selected packet. Documentation
   repairs can start independently once their literal source mapping is frozen.
2. Freeze Task 39's shared failure-fact contract and one connected representative
   slice before releasing its dependent command-family edits. A family inventory
   is not an executable mutation packet.
3. Release disjoint documentation jobs alongside the accepted error foundation.
   Navigation diagnosis is complete; release its bounded corrections only after
   the recorded output decisions are accepted.
4. Drain the entire mutation wave. Then the coordinator runs shared builds,
   formatting, focused tests and the integrated managed/native gates. No worker
   rebuilds the shared output tree while siblings are changing source.
5. Inspect diffs and actual evidence, resolve concrete integration findings,
   update task state, and only then make a coherent authorized local commit.

The coordinator alone owns task indexes, project control, this packet, shared
command-contract updates, shared output-text identifiers, and final snapshot
acceptance. Task 39 must exclude Doctor navigation files reserved by the
navigation packet. Operations and Rendering for one feature are assigned together,
not twice. Transfer a file only after the preceding worker is finished and its
partial changes are inspected.

Reserve one ignored receipt per worker, `.temp/beta-follow-ups/receipts/<slice>.md`.
Before release the coordinator records exact agent/run identity, file allowlist,
predecessor evidence, immutable input hashes, immediate checks and the deferred
integrated gate in the local dispatch record. Workers report changed files,
checks, unexpected findings and unresolved conditions. Their completion messages
are not acceptance. Corrections use an idle worker; Worker Watch cannot steer a
running worker safely.

## Completion and safeguards

The current deliverable is a reviewed specification, with evidence-backed ready
work separated from unresolved design. Implementation follows the accepted slice boundaries and execution gates. Preserve statuses, exits, streams, JSON shape,
filesystem effects, native resources and genuine OS evidence. Deliberate wording
changes need situation-specific expected text and reviewed snapshot changes.
Never regenerate a broad corpus to hide a regression.

There is no new filesystem mock system, general filesystem abstraction, template
engine, routing sweep, release, push or hosted pipeline run in this packet.
Pure formatting/fact mapping tests need no disk; real filesystem failures keep
real OS evidence. Roll back an abandoned slice by reviewing and reversing only
its owned hunks, preserving all pre-existing and sibling work.
