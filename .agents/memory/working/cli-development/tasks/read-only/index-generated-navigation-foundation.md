## Outcome

Create one neutral `Framework/GeneratedNavigation/**` capability that consumes
already accepted source topology and authored metadata facts, recognizes an
already selected valid generated region, forms canonical direct-child `Entries`
bytes including the empty projection, deduplicates by physical identity, retains
deterministic ordinal order, and returns immutable expected-region and bounded
change facts. It performs no filesystem effect.

## Architecture And Ownership

Owned production paths are new files below
`src/cli/core/OpenForge.Cli.Core/Framework/GeneratedNavigation/**`. Owned tests
are the mirrored Unit and real-filesystem Integration paths. New property-only
types belong under the nearest cohesive `Models/` scope; supporting behavior uses
named capabilities rather than `Common`, `Utils`, or a generic service bag.

The capability may read through accepted Framework source, routing, Markdown,
YAML, strict-UTF-8, and physical-identity callables. It must not modify their
semantics. If an accepted callable is insufficient, return a project change
request instead of creating a local parser, source catalogue, identity model, or
replacement contract.

Protected paths are every `Commands/**` path, root composition,
`CliJsonContext`, Extension, Lifecycle, Mutation, Recovery, locking, Git,
projects, packages, configuration, and generated Markdown. The lane does not add
Index symbols, flags, request/result types, renderers, JSON, application,
temporary/backup artifacts, or public-process evidence.
