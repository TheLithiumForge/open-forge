## Execution Capsule

### Contract-Closure Outcome

Freeze one exact command-local result model subordinate to the accepted Interface
and Behavior contracts. It must name the stable JSON fields and finite values for
workspace/source identity, installed and available state, lifecycle trust and
coverage, dependency closure, declared/current path facts,
baseline/current/intended comparison, generated-navigation ownership, findings,
status, and at most one `next` action. Freeze the finding order and status
precedence without adding lifecycle or mutation authority.

Freeze one neutral `open-forge-markdown-v1` fingerprint contract for accepted
Markdown package payloads. The recommended conservative boundary is strict UTF-8,
fixed parser validation, line-ending normalization only, exclusion of only a
valid generated `Entries` interior while retaining its marker identity, retention
of every other authored byte, and lowercase SHA-256. Unsupported, binary,
unparseable, or invalid-boundary inputs use exact-byte identity or fail closed as
the accepted contracts require.

The contract-closure increment may update only the Inspect Crystallized
contracts, this leaf Task's contract/evidence sections after Overseer acceptance,
and directly linked public examples. It changes no C# source or tests.
