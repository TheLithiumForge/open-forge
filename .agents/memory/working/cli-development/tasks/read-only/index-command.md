### Deferred Shared-Reader Finding

`Framework/Sources/Reading/SourceDocumentReader.cs` contains a pre-existing
workaround that inspects `FilesystemFailure.DirectCause` for HResult-like text
when distinguishing access-denied sharing failures from ordinary input/output
failures. Index neither adds nor directly consumes that text classification:
both resulting typed read states map to the same role-specific incomplete
finding and command-authored cause, so current Index behavior is unaffected.

Do not expand this task into the protected shared reader. A separate typed
shared-reader cleanup must remove the text parsing, preserve cross-platform
failure semantics, and provide its own focused evidence before any consumer
claims the cleaner boundary.

The accepted neutral reason-to-Index mapping is exhaustive:

| Index finding | Neutral GN1 reasons |
| --- | --- |
| `index.target-unsafe` | `RegionSourceUnsupported`, `TopologyUnsafe`, `DestinationUnsafe`, `DestinationConflict` |
| `index.generated-region-unsafe` | `GeneratedRegionMissing`, `GeneratedRegionInvalid`, `GeneratedRegionLineEndingUnsupported` |
| `index.metadata-unsafe` | `MetadataInvalid`, `MetadataUnrepresentable` |
| `index.discovery-incomplete` | `TopologyUnavailable` |
| `index.metadata-incomplete` | `MetadataUnavailable` |
| `index.projection-incomplete` | `SourceDocumentUnavailable`, `GeneratedRegionUnavailable`, `ProjectionUnavailable` |

Typed acquisition findings remain authoritative when they are more specific
than a later residual projection reason. `TopologyUnavailable` is defensive
under the canonical formation because its topology and retained sources are
derived together. `DestinationConflict` is defensive after unique canonical
sources, injective destination encoding, and physical-alias deduplication.
`ProjectionUnavailable` is the defensive valid-input construction fallback.
Tests exercise reachable behavior rather than constructing invalid formation
states or freezing the enum as a brittle authored inventory.

C# enums also admit unnamed numeric values, so Index uses one grouped switch
expression that lists every named GN1 reason and ends with an
`ArgumentOutOfRangeException` guard for an undefined value. Focused behavior
evidence covers every named mapping and the undefined-value guard; this does not
claim compiler-enforced exhaustiveness or suppress the compiler's enum warning.
