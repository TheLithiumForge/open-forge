internal enum LifecycleDocumentSnapshotState

    internal static LifecycleDocumentSnapshot Missing(

    internal static LifecycleDocumentSnapshot Blocked(
        CliWorkspace workspace,
        FileStateSnapshot? file,
        string cause);

    internal static LifecycleDocumentSnapshot Unavailable(
        CliWorkspace workspace,

        LifecycleDocumentFailureStage failureStage);

    internal static LifecycleDocumentSnapshot Interrupted(

logical path, confirmed physical path, immutable bytes, and content identity;

directory snapshot when that is the blocking observation. `Unavailable`
carries only a typed bounded `FilesystemFailure` and one required defined
`FailureStage`; its file and cause are null. `Interrupted` carries only its
finite state and workspace. Every state other than `Unavailable` has null
`FailureStage`. Encoding and syntax failures cannot be mechanical document-read
failures. `ContainedFileAccess` accepts only access-denied or input/output
failures; resolution and reconfirmation accept only the existing physical-
