# Archived CLI Development

This route preserves the replacement-CLI working state moved out of active
context on 2026-09-11. Task 30 and Task 31 were rebuilt as compact open records;
the files here retain their pre-cleanup detail and provenance.

Nothing in this route is the current CLI plan or Task authority. Read the active
[CLI Development route](../../working/cli-development/_cli-development.md) first
and restore historical material only for a concrete question.

## Axioms

- Preserve history without allowing it to act as current Working Memory.
- Do not rewrite a historical record to match later implementation state.
- A historical record may be copied into a new active Task only after its facts
  are checked against current sources and accepted direction.
