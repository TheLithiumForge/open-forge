# Archived CLI Release Review

This route preserves historical CLI release material after accepted direction
settled the corresponding units. It is contextual history, not current CLI
authority. Its descendants include the Gate 1 audits and registers, the contract
migration ledger, and settled or rejected review records.

The retained Gate 1 set includes the [audit](gate-1-audit.md), [findings](gate-1-findings.md), [handoff register](gate-1-handoff-register.md), and [repository register](gate-1-repository-register.md). The [contract migration ledger](contract-migration-ledger.md) records the completed lossless migration.

The active CLI release program remains under
[`../../working/cli-release/_cli-release.md`](../../working/cli-release/_cli-release.md).
There is no active command review queue. The former queue and its review records
remain under [`review/`](review/_review.md) as historical context. Accepted
behavior, Architecture, and contract structure remain in the current
[Crystallized CLI sources](../../crystallized/documents/cli/_cli.md). The
descendants here preserve origin, reasoning, dissent, and evidence only.

## Archive Rules

- Treat every descendant as `#Archived`, `#Historical`, and `#Contextual`.
- Do not use historical council reasoning as current CLI authority.
- Validate historical material against current sources before restoring or reusing
  it.
