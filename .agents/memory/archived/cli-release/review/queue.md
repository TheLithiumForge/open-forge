line evidence already in context. Use bounded exploration only for missing
facts, and preserve cold isolation only when independent reasoning is the point.

own checks stay focused on links, obvious consistency, and diff hygiene rather
than becoming another extensive review. Use one appropriately scoped reviewer
or writing-reviewer at the end of a meaningful batch, not one reviewer per file.
Run a council only for a material unresolved tradeoff or when the maintainer asks
for one.

## Review State Rules

- Move active items to `reviewing` only when their bounded pack is the current
  maintainer discussion.
- Move it to `revision-needed` or `direction-recorded` only from explicit
  maintainer feedback.
- A review file remains contextual and unaccepted after any result is
  integrated into the appropriate current contract, Decision, Template, or
  current document. This does not change the linked contract's authority.
- Present and author one coherent active pack at a time. Do not advance an
  unrelated pack silently.
- Run another council only for a material unresolved disagreement, new
  evidence, or a maintainer-requested alternative. Do not use councils as
  voting rounds.
- Give helpers exact sources and accepted constraints already known. Do not pay
  for repository-wide rediscovery, duplicate reviews, or deep writer self-review
  when a focused correction check is sufficient.
