# Archived CLI Review

This route contains review records moved from the CLI release queue after their
units settled. It includes the older council records and the settled Gate 2
records for Queues 28–33. Each descendant preserves historical analysis, dissent,
and evidence. It does not replace the current source linked from its status
record.

No command review is active. The former [review queue](queue.md) is retained as
historical disposition context. Use the current source named by each archived
record for accepted behavior or structure. The current sources are the accepted
[CLI Architecture](../../../crystallized/documents/cli/architecture.md), the
overview/shared Documents, and the detailed contracts. Restore historical
material only after validating it against current direction. The [Gate 2 review
overview](gate-2-review-overview.md) is an ordinary historical overview, not this
entrypoint or a source of current authority.

## Archive Rules

- Treat every descendant as `#Archived`, `#Historical`, and `#Contextual`.
- Do not treat historical recommendations, candidates, generated entries, or
  council reasoning as current authority.
- Keep origin and archival reason visible in each record.
