# Expense splitter

A command-line tool that splits shared expenses between friends and shows who owes whom. It's small enough to finish in one session and has exactly the kind of rules that go wrong quietly: money must stay in whole cents, and someone has to absorb the leftover cent.

- [Greenfield](greenfield/): build it from an idea, at four levels of detail.
- [Brownfield](brownfield/): add percentage splits to a half-built version whose important rules live only in the author's notes.
