# Observations

## Essence

Observations defines what `{forgePath}/observations/_observations.md` and `{forgePath}/observations/` should do in the installed framework.

Observations are candidate lessons found during work. They are pseudo-truth, not active truth.

## Use When

- An agent notices repeated friction.
- A rule, guide, pattern, or workflow may be missing.
- A local behavior keeps recurring but is not yet approved.
- A future human review should decide whether to promote something.

## Do Not Use When

- The statement is already active truth.
- The user explicitly approved a directive, guide, pattern, or workflow update.
- The content is a session summary or temporary handoff.

## Default Rules

- Store active candidates in `{forgePath}/observations/`.
- Archive reviewed or stale observations in `{forgePath}/observations/archive/`.
- Promote observations only after human review or explicit instruction.
- Review observations from time to time; do not let them become a junk drawer.

## Useful Notes

Observation files should be small and pointed. The useful question is: "Should this become a rule, guide, pattern, workflow, or nothing?"
