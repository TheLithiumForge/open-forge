# Templates

## Essence

Templates defines what `{forgePath}/templates/_templates.md` and `{forgePath}/templates/` should do in the installed framework.

Templates are reusable skeletons for creating new artifacts.

## Use When

- A repeated artifact needs a consistent starting shape.
- Creating handoffs, observations, sessions, evidence notes, or work packages.
- A local workspace wants its own preferred artifact format.

## Do Not Use When

- The template would become active truth by itself.
- The content is a full example pretending to be a default.
- The local process is too divergent for a shared template to help.

## Default Rules

- Templates should help start an artifact, not force a whole process.
- If a template is wrong for the workspace, edit it or add a local one.
- Do not ask agents to reconcile contradictory templates.
- Use overwrites only when base plus overwrite remains clear.

## Useful Notes

Templates are where helpful repetition belongs. Fake completeness belongs nowhere near the forge.
