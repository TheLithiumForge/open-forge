# Technology
Technology is a specification that defines requirements for Neon Pairs.

## Stack

- T01.1 - Use React and TypeScript with DOM rendering.
- T01.2 - Use native buttons and a native select.

## Commands

- T07.4 - npm test runs game rule unit tests.
- T07.6 - npm run build type checks and writes dist/index.html.
- T07.9 - Stop development servers and watchers started during the work before finishing.

## Distribution

- T08.1 - dist/index.html contains all script, styles and artwork for play.
- T08.2 - Open it directly from disk without other files or network requests.
- T08.3 - Use the system font.
- T08.4 - Keep browser zoom enabled.

- T09.2 - Storage failure leaves the current session playable.

- T10.2 - The game uses no service, account, external asset, analytics or API key.
- T10.3 - Dependency installation can use the network.
- T10.4 - Playing the distribution makes no network requests.
