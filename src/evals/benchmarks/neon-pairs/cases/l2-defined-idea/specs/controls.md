# Controls
Controls is a specification that defines requirements for Neon Pairs.

## Deal controls

- C01.1 - Use a native select named Grid size.
- C01.2 - Offer 4x4, 6x6, 8x8, 10x10, 12x12, 14x14 and 16x16.

- C02.1 - Name the fresh-deal button New Game.
- C02.2 - Start a fresh deal at the current size.

- C03.1 - Name the repeat-deal button Restart.
- C03.2 - Repeat the same deal.

## Focus

- C13.1 - Keep focus on New Game and Restart after activation.
- C13.3 - These actions don't move focus to the board.
- C13.5 - Use [I12](input.md#focus) for the remembered board tab stop after a deal change.
