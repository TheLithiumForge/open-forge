# Feature status

This page lists what the game can do today and what has only been discussed.

Use it to answer "does the game do that yet?" without reading the source. A feature counts as built when a person can use it in the released game.

| Feature | Status | Where |
| --- | --- | --- |
| Solo play on seven board sizes | Built | `src/game/game.ts`, `src/game/board/` |
| Board codes that repeat a deal | Built | `src/game/deck.ts` |
| Progress export and load | Built | `src/game/snapshot.ts`, `src/game/controls/` |
| Replay from recorded moves | Built | `src/game/replay.ts` |
| Best scores by board size | Built | `src/game/session/` |
| Keyboard play | Built | `src/game/board/` |
| Tournament mode | Not built | None |
| Online play | Dropped | None |
| Timed mode | Dropped | None |
| Hints | Dropped | None |
| Themes | Dropped | None |

[Competition overview](competition-overview.md) explains what shared-device competition is for. The retired idea pages say why the dropped features stopped.
