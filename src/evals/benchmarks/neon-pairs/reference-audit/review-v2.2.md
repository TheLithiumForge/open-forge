# Version 2.2 Review

Version 2.2 Review is the correction record for the maintainer's spec trim and the fifth reference round. The trim drops rules for corners that players and agents rarely reach. The fifth round had stopped partway with seven aims, and this record says which of them the trim keeps.

For example, Ctrl+End on a card that already has focus is now the browser's key, so the reference no longer needs a fix for its missing outline.

Status: corrected candidate for spec version 2.2. Independent judgment is pending. Spoken output stays user acceptance.

## Spec trim

The maintainer approved the trim on 2026-11-01. The [spec notes](../../../../../.agents/memory/crystallized/documents/evals/neon-pairs/spec-notes.md#maintainer-trim) log each decision. The reference follows them:

| Item                 | Clauses               | Change                                                                                                                                                                                                                              | Test                                                                                                                                                                                                        |
| -------------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1, retired keys      | I06.5 to I06.8, I02.1 | Home, End, Ctrl+Home and Ctrl+End no longer move focus. The card's autorepeat guard is gone. Browser tests reach far cards with arrow keys instead.                                                                                 | The Home and End unit test and both autorepeat browser tests are removed. Mutation M29, the outline request for Ctrl+End, is retired.                                                                       |
| 2, unlisted keys     | I06.10                | `navigationTarget` returns a target only for the four arrow keys without modifiers. Every other key and modifier combination keeps its browser behavior.                                                                            | The keyboard unit test covers modifiers with arrows, Ctrl+End, Home, End and Tab. `tests/keyboard.e2e.test.ts` presses Alt+ArrowLeft and Ctrl+End on a focused card. Mutation M41 drops the modifier check. |
| 3, export times      | C08.6, C08.7          | No product change. Export still rounds elapsed time down and pending time up, which gives whole milliseconds and keeps a pending mismatch at 1ms or more. The tests now accept any whole millisecond within 1ms of the active time. | The snapshot unit test and `tests/fractional-clock.e2e.test.ts`. Mutation M38, rounding to nearest, is retired. | 4, one tab at a time | R08, R10.3, R10.6     | The storage event sync is gone, and a write no longer shows the merged bests. The two multi-tab saved-best journeys are removed, with mutation M37.                                                             |

The reference now leaves Shift+Enter, Shift+Space, Ctrl+Space and Alt+Space to the browser. Chromium's native button activates a card for them, as it does for Enter and Space. The Out of scope list in the spec README covers these combinations, so the reference adds no guard.
