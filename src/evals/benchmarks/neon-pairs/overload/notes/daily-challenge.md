# Idea: Daily Challenge

Raised at the October planning chat. Not adopted.

Everyone would get the same board each day, built from a board code derived from the date. Players could compare their moves for the day.

Open questions:

- Which time zone decides the day.
- Whether a daily best should live beside the normal best scores or replace them.
- Whether the date should show in the board code.

Nobody owns this yet, and it would need its own spec before any code.
