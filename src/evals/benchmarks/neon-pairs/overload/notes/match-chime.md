# Idea: A Chime on Each Match

Raised by a tester in week 3. Rejected.

The idea was a short tone on each match and a longer one on a win, made with Web Audio so there would be no sound files. Two testers liked it in a quick trial.

It was rejected because the game is meant to be silent, so it can be played anywhere without surprising anyone, and feedback stays visual and announced. A mute switch was suggested as a compromise and rejected too, because it adds a setting to explain.

Status: rejected. Kept here so the idea isn't raised again without this context.
