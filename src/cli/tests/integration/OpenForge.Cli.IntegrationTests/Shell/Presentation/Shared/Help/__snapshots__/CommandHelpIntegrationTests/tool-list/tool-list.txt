  List supported tools and their setup profiles.

Usage:
  open-forge tool list [options]

Examples:
  open-forge tool list
  open-forge tool list --format json

Behavior:
  Lists catalogue entries and any project declarations. Changes no files.
  Use Inspect for channels, requirements and native effects before installation.

Global options: --workspace, --format, --detail, --detail-filter, --help,
--version. See open-forge --help.

Automation:
  --format json: one minified schema-3 JSON result on stdout for every status.
  Exit codes: 0 completed, 1 failed, 2 completed with warnings, 3 incomplete, 4
  invalid input, 5 blocked, 130 cancelled.
  Text exits 0, 2, 3: stdout. Others and bounded debug diagnostics: stderr.

Related commands:
  tool list
  tool inspect <id>
  tool status [id]
  tool install
  tool update
  tool remove <id>
