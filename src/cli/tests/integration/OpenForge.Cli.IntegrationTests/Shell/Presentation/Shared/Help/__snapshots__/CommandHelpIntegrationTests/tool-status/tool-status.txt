  Check tool versions, project additions and PATH readiness.

Usage:
  open-forge tool status [<id>] [options]

Examples:
  open-forge tool status
  open-forge tool status codegraph --format json

Behavior:
  Checks declared or locked tools, or one named catalogue entry. Changes no
  files.
  Compares the lock with this machine and checks recorded project additions and
  native settings.
  Restart terminals and agent apps after PATH changes, then check again.

Arguments:
  <id>  The exact catalogue tool ID.

Global options: --workspace, --format, --detail, --detail-filter, --help,
--version. See open-forge --help.

Automation:
  --format json: one minified schema-3 JSON result on stdout for every status.
  Exit codes: 0 completed, 1 failed, 2 completed with warnings, 3 incomplete, 4
  invalid input, 5 blocked, 130 cancelled.
  Text exits 0, 2, 3: stdout. Others and bounded debug diagnostics: stderr.

Related commands:
  tool list
  tool inspect <id>
  tool status [id]
  tool install
  tool update
  tool remove <id>
