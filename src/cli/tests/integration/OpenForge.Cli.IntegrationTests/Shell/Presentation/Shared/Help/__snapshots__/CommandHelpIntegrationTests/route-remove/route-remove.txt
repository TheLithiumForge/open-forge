  Remove one routed file or category and remember the removal.

Usage:
  open-forge route remove <source-reference> [options]

Examples:
  open-forge route remove guidance --dry-run
  open-forge route remove guidance
  open-forge route remove guidance --automatic

Behavior:
  --dry-run shows the complete plan and writes nothing.
  A category selects its whole routed category, not just the entrypoint.
  Framework- and Extension-managed content can be removed when safety checks
  allow it.
  Open Forge records the removal so updates do not restore it.
  An interactive writing plan asks for confirmation unless --automatic is
  supplied.
  Redirected or JSON requests that would write need --automatic.
  Interrupted removals report retained recovery data for review.

Arguments:
  <source-reference>  Select one routed source or category by ID or exact path.

Options:
  --dry-run    Preview the complete removal plan without writing.
  --automatic  Apply the planned removal without asking for confirmation.

Global options: --workspace, --format, --detail, --detail-filter, --help,
--version. See open-forge --help.

Details:
  Safety: Select a Markdown file by exact ID, base path, or overwrite path, or a
  category by its recognized entrypoint. The Loader and .agents root are
  protected. A leaf cannot be a native Skill, non-Markdown resource, or orphan
  or ambiguous overwrite. Categories include all contained regular files and
  folders, including native and binary resources. Links, special files,
  incomplete scans, unsafe references, or nested .git repositories block the
  whole removal.
  References and restoration: Supported incoming links outside the subject
  become their visible labels. Apply locks the workspace, rechecks files,
  releases matching managed claims after verification, and updates generated
  Entries. Removal records file or directory exclusions. To restore content,
  clear every covering exclusion in .agents/open-forge.json and explicitly run
  the relevant installer or updater. Remove never follows links or invokes
  another command.

Automation:
  --format json: one minified schema-3 JSON result on stdout for every status.
  Exit codes: 0 completed, 1 failed, 2 completed with warnings, 3 incomplete, 4
  invalid input, 5 blocked, 130 cancelled.
  Text exits 0, 2, 3: stdout. Others and bounded debug diagnostics: stderr.

Related commands:
  remove --help      Choose one exact removal target.
  references --help  Inspect authored links.
  cleanup --dry-run  Preview recovery-data cleanup.
