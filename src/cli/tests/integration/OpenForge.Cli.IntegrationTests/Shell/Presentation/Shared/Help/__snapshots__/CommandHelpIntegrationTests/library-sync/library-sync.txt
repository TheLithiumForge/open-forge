  Bring a registered Library's links into agreement with its source files.

Usage:
  open-forge library sync <library-id> [options]

Examples:
  open-forge library sync shared --dry-run
  open-forge library sync shared
  open-forge library sync shared --automatic

Behavior:
  Select one registered Library. Compare its links with the complete current
  source inventory.
  --dry-run shows the complete plan and writes nothing.
  An interactive writing plan asks for confirmation unless --automatic is
  supplied.
  Redirected or JSON requests that would write need --automatic. External
  destinations need permission. Interrupted writes report recovery data.

Arguments:
  <library-id>  Select one exact Library management ID.

Options:
  --dry-run            Preview the complete plan without writing.
  --automatic          Disable prompts. Does not select or alter Library
                       targets.
  --allow-path <path>  Permit writing to this workspace-relative path, recording
                       it in .agents/open-forge.json.

Global options: --workspace, --format, --detail, --detail-filter, --help,
--version. See open-forge --help.

Details:
  Permission: --allow-path records permission for an exact destination outside
  .agents. The target is verified before writing.

Automation:
  --format json: one minified schema-3 JSON result on stdout for every status.
  Exit codes: 0 completed, 1 failed, 2 completed with warnings, 3 incomplete, 4
  invalid input, 5 blocked, 130 cancelled.
  Text exits 0, 2, 3: stdout. Others and bounded debug diagnostics: stderr.

Related commands:
  library inspect --help  Inspect one Library and its links.
  repair --help           Correct verified link and Library problems.
  library detach --help   Detach links while keeping source files.
