  Install tools, run native setup and add project configuration.

Usage:
  open-forge tool install [<id[@version]>] [--channel <channel>] [--yes] [--allow-path <path>...] [--dry-run]

Examples:
  open-forge tool install codegraph@1.6 --dry-run
  open-forge tool install codegraph@1.6 --yes
  open-forge tool install

Behavior:
  Without a name, restores exact lock versions for teammates. A named bare ID
  selects latest support.
  Use ID@major.minor or ID@exact stable SemVer. --channel selects an advertised
  channel for a named tool.
  Review native effects and Open Forge additions with --dry-run. Latest lookup
  can use the network.
  --yes accepts the plan and downloads. PATH edits and shared deletion need
  separate live choices.
  Native setup keeps its MCP entries, hooks, permissions, instruction blocks and
  Skills.
  CodeGraph telemetry is turned off. Codebase Memory uses default account
  discovery and watcher settings.

Arguments:
  <id[@version]>  A tool ID, ID@major.minor or ID@exact stable SemVer.

Options:
  --yes                Accept the shown plan and downloads. Skip PATH edits,
                       shared deletion and account-wide uninstall.
  --dry-run            Show the checked plan without applying changes.
  --allow-path <path>  Permit writing to this workspace-relative path, recording
                       it in .agents/open-forge.json.
  --channel <channel>  Select an advertised channel for a named tool.

Global options: --workspace, --format, --detail, --detail-filter, --help,
--version. See open-forge --help.

Automation:
  --format json: one minified schema-3 JSON result on stdout for every status.
  Exit codes: 0 completed, 1 failed, 2 completed with warnings, 3 incomplete, 4
  invalid input, 5 blocked, 130 cancelled.
  Text exits 0, 2, 3: stdout. Others and bounded debug diagnostics: stderr.

Related commands:
  open-forge tool inspect <id>
  open-forge tool status
