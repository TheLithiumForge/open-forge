  Show whether Open Forge is installed and whether its setup needs attention.

Usage:
  open-forge status [options]

Examples:
  open-forge status
  open-forge status --detail standard
  open-forge status --format json

Behavior:
  Inspect the current workspace, or select another with --workspace.
  The default gives a short installation and context summary.
  Use --detail standard for reasons and next actions. This command changes no
  files and asks no questions.

Global options: --workspace, --format, --detail, --detail-filter, --help,
--version. See open-forge --help.

Details:
  Coverage: Inspect installation, startup and continuity context, generated
  navigation, lifecycle, managed targets, and exact recovery candidates. This
  deterministic, stateless command takes no workspace lock, repairs no lifecycle
  state, and restores no recovery data.

Automation:
  --format json: one minified schema-3 JSON result on stdout for every status.
  Exit codes: 0 completed, 1 failed, 2 completed with warnings, 3 incomplete, 4
  invalid input, 5 blocked, 130 cancelled.
  Text exits 0, 2, 3: stdout. Others and bounded debug diagnostics: stderr.

Related commands:
  doctor          Diagnose workspace problems.
  context         Read agent instructions and context.
  install --help  Install or configure the Framework.
