# Maps

Routes under Maps point to important local and external sources. The destination still defines its own detail.

## Axioms

### Selection And Destinations

- Check `Entries` when the work needs an important local or external source.
- Each Map route links to one or more destinations and says what they contain and when they matter.
- Local links are relative to the Map file that contains them. External sources use their normal URL.

### Map Boundaries

- Keep routes under Maps intentionally broad. Prefer modules, projects, repositories, systems, or scopes over members and functions unless finer routing is clearly useful.
- Each workspace chooses its own route filenames, grouping, and nesting depth.
- Routes under Maps do not replace Memory or the destination's current information.
