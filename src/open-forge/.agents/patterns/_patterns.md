# Patterns

Optional. Each Pattern shows one reusable shape for code, files, APIs or documents, so related work looks alike. Nothing else depends on this folder.

## Axioms

- Follow a matching Pattern by default. When the work needs something different, adapt it and explain the difference before other work depends on it.
- Show the shape as an example, tree, table or outline, and label which parts are required and which are only illustrative. Keep examples valid, or label them schematic.
