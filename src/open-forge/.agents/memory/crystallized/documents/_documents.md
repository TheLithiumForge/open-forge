# Documents

Documents are durable accepted records or routes to them.

## Axioms

- This entrypoint exposes long-form accepted context and routes to document destinations.
- Read `Entries` when current work needs durable accepted records.
- Treat documents as current memory within their stated scope unless they declare another source of truth.
- The routed destination owns detailed truth when a document entry points outside itself.
- Keep templates and document-generation behavior in the route that owns that behavior.
- Avoid duplicate current truth; update, split, merge, or link existing document routes instead.
- Extract operational behavior, reusable form, or generation rules from documents to matching #Core routes.
- Archive or link superseded documents with enough context to understand what replaced them.
- Load only the document bodies and child categories relevant to the current request.
- Add child categories when they improve routing, ownership, or clarity.
- Generated entries are navigation and reserved load policy only.
