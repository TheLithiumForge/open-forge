# Save progress

Optional policy. To stop automatic saving, delete this file and remove its entry from `_working.md`. Working records stay. If the CLI manages updates, record the removal so updates do not restore it. Needs Working Memory.

## Instructions

- Before you pause or hand off work that is not finished, update its record in Working Memory, or create one: the goal, where it stands, the next step and open questions.
- Save only what another session needs. Finished work needs no record unless its outcome still matters.
