# Working Memory

## What temporary context is needed to continue or resume this work?

This folder holds records of unfinished work, so another session can pick it up.

## Axioms

- Check these Entries before deciding that no Working record applies. At the start or resume of a task, read the record of that work if there is one, and check it against the current files.
- Before you pause or hand off work that is not finished, update its record here, or create one. Save only the temporary state another session needs to resume or transfer the work. Finished work needs no record unless its outcome still matters.
- Keep each record small, current and easy to replace: the goal, where it stands, the next step and open questions.
- An explicitly accepted temporary choice may stay here when its source, scope and expected expiration are clear.
- When the active need ends, keep useful results where they belong, then move, consolidate or prune the record.
