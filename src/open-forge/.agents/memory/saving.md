# Save progress

Optional policy for Working Memory. It does nothing when Working Memory is not installed. It sits beside the Memory folders so it stays shared through Git even when Working records are private. To stop automatic saving and keep your Working records, delete this file and remove its entry from `_memory.md`. If the CLI manages updates, record the removal so updates do not restore it.

## Instructions

- Before you pause or hand off work that is not finished, update its record in Working Memory, or create one: the goal, where it stands, the next step and open questions.
- Save only the temporary state another session needs to resume or transfer the work. Finished work needs no record unless its outcome still matters.
