# Open Forge

Open Forge provides the working rules and context for this workspace.

Before starting or resuming a task, read `.agents/loader.md` and follow it throughout the task. If the `open-forge` CLI is available and allowed, `open-forge context --for <file>` gathers the required reads, with `--for` repeated for every working file. The loader says which other files to choose and how to continue with file tools when the CLI is unavailable.
