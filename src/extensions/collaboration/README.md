# Collaboration

Explore an uncertain direction with concrete alternatives, useful questions, and enough detail to make a decision.

## What You Get

| Source                                                                             | Use it to                                                                    |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| [Adaptive Collaboration](content/.agents/guidance/adaptive-collaboration.md)       | Get advice on exploration, questions, convergence, and proportionate review. |
| [Brainstorming Template](content/.agents/templates/collaboration/brainstorming.md) | Preserve a useful comparison when the conversation alone is insufficient.    |

**Direct dependencies:** None.

The package's Guidance and Template remain on demand.

## Relationship With Planning

Collaboration helps clarify a direction. Planning organizes accepted work into an executable sequence. Either can be used independently. Exploration is not a required stage before action.

Keep a brainstorm in an existing Emerging Memory scope until its outcomes are accepted. The optional Planning package supplies Ideas and Analysis when those conventions help. This package adds no competing brainstorming category, task lifecycle, or acceptance rule. Move accepted outcomes into the sources that define them, preserving useful unresolved alternatives separately.

## Install And Customize

See the [installation guide](../../../docs/extensions.md). Copies of the Template are maintained independently.

Adaptive Collaboration keeps its installed path, `.agents/guidance/adaptive-collaboration.md`, after leaving Core. Existing workspaces may still have a Core-owned or edited copy. Inspect ownership and preview removal of the retired Core copy before installing this package. Preserve local changes. Matching bytes do not authorize ownership transfer. A fresh install has no such migration step.
