# Vision Workflow

Workflow-only extension for turning early intent into a decision-ready direction without prematurely treating candidates as accepted truth. It clarifies core value, first-useful-version boundaries, non-goals, risks, terminology, validation signals, and a minimal warranted bundle of directives, patterns, guidance, workspace routes, and memory.

Every candidate is labelled user-stated, observed, or inferred. Normative Core or CurrentTruth material requires user accord; useful unaccepted deductions stay emerging or are returned as proposed routes.

It depends on `vision-capability`; the selector marks that skill extension as required automatically.

```sh
open-forge extend vision-workflow
```
