# Clarify Intent

## Use When

Use when the requested direction is still broad, contradictory, or missing a clear reason.

## Capability

- Ask for the problem, user, desired outcome, constraints, and non-goals.
- Separate what the user wants from what the project actually needs.
- Surface assumptions that would change the direction if wrong.
- Keep questions short and grouped by decision.

## Expected Result

The workflow has enough intent to define a vision or identify the next question that matters.
