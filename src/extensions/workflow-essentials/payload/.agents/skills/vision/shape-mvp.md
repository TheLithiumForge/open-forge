# Shape MVP

## Use When

Use when a vision needs a first useful version instead of an unlimited feature set.

## Capability

- Identify the core value that must work first.
- Separate required MVP behavior from later enhancements.
- Name explicit non-goals for the first version.
- Preserve future directions without letting them bloat the MVP.

## Expected Result

The workflow can state what must be built first, what should wait, and why.
