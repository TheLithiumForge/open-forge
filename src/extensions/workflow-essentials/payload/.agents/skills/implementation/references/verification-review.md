# Verification Review

## Use When

Use after implementation before final response, handoff, or memory extraction.

## Capability

- Run or inspect the relevant verification.
- Compare the final behavior to the goal, tests, and loaded patterns.
- Improve names, boundaries, duplication, error handling, and clarity when tests provide guardrails.
- State residual risk and verification gaps plainly.

## Expected Result

The user gets a verified change with clear remaining risk instead of an unexamined patch.
