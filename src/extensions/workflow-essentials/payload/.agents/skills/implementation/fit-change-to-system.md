# Fit Change To System

## Use When

Use before editing when the change touches code, docs, routing, architecture, or shared behavior.

## Capability

- Read the existing structure before proposing shape.
- Identify owners, boundaries, APIs, data flow, and relevant patterns.
- State the minimal change path and the expected blast radius.
- Report conflicts between the requested change and loaded project rules.

## Expected Result

The implementation has a concrete design that fits the system before files are changed.
