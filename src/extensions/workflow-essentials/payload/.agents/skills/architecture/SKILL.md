# Architecture

Use this skill to reason about structure before implementation.

## Process

- Ground architecture work in loaded source files, accepted memory, and current workspace constraints.
- Separate current state, proposed direction, rejected options, and implementation slices.
- Keep rationale in the route that owns accepted memory; keep behavior in the route that owns behavior.
