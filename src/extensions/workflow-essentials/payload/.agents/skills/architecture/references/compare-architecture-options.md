# Compare Architecture Options

## Use When

Use when there are multiple plausible structural directions or when a preferred option needs pressure testing.

## Capability

- Name each viable option in concrete terms.
- Compare fit with goals, current patterns, constraints, complexity, testing, operations, and migration effort.
- State what each option makes easier, harder, safer, or riskier.
- Recommend one direction only when the evidence supports it.

## Expected Result

The user can see the real tradeoffs instead of only a favored architecture.
