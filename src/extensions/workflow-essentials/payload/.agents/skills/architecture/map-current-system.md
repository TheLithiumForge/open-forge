# Map Current System

## Use When

Use before proposing architecture, large refactors, migrations, or structural documentation.

## Capability

- Identify relevant source roots, modules, packages, boundaries, and owners.
- Trace key data flow, control flow, runtime constraints, and integration points.
- Load accepted #Memory and #Workspace routes that explain current truth.
- State unknowns that would materially change the architecture.

## Expected Result

The workflow has a grounded map of the current system before evaluating changes.
