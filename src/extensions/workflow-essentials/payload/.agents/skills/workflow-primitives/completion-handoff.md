# Completion Handoff

## Use When

Use before ending meaningful workflow work, especially when work may continue in another context.

## Capability

- State what changed or was learned.
- State what was verified and what remains unverified.
- Identify blockers, decisions needed, and the next concrete action.
- Point to loaded routes, changed files, or memory candidates needed for resume.
- Write or propose a handoff only when a static resume note would help.

## Expected Result

The user or next agent can resume without relying on opaque chat memory.
