# Loaded Context Check

## Use When

Use when a workflow is about to make a decision, edit files, create accepted memory, or hand off work.

## Capability

- Identify the active goal and selected workflow.
- List the loaded routes that currently constrain the work.
- Load missing routes when their path, description, or tags make them relevant.
- State any important missing context that cannot be loaded.

## Expected Result

The agent knows which loaded files constrain the next action and which assumptions remain unverified.
