# Memory Routing

## Use When

Use when workflow output may be worth saving beyond the current response.

## Capability

- Separate accepted truth, candidate learning, raw session history, transfer notes, and historical context.
- Suggest the narrowest #Memory route that owns each useful output.
- Extract operational behavior, reusable form, guidance, capability, workflow, or workspace routing to the matching #Core route when it no longer belongs only in memory.
- Ask before creating accepted truth when user confirmation is needed.

## Expected Result

Useful output has an explicit owner, and stale private agent memory does not become the hidden source of truth.
