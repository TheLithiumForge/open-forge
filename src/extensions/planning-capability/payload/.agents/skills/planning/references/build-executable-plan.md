# Build Executable Plan

## Capability

- Confirm the accepted outcome, scope, non-goals, constraints, and acceptance evidence.
- Inspect current system, work, and verification boundaries before choosing steps.
- Order coherent steps by dependency and give each an observable result and check.
- Expose parallel work, decision points, containment needs, and residual uncertainty.

## Expected Result

Another capable agent can execute the plan without guessing material intent.
