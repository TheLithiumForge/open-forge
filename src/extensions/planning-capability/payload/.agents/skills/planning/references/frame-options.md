# Frame Options

## Capability

- Bound the problem, desired outcome, users, constraints, and unknowns.
- Inspect available evidence before generating alternatives.
- Compare materially distinct options by value, cost, risk, reversibility, dependencies, and evidence gaps without padding the option set.
- Recommend only when evidence supports a direction; otherwise name the smallest resolving decision or experiment.

## Expected Result

Candidate directions are comparable without being mistaken for accepted commitments.
