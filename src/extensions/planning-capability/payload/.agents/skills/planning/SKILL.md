# Planning

Turn uncertain intent into decision-ready options or one executable path.

## Process

- When task state is involved, use exactly one authoritative source declared by the user or workspace for status, ownership, acceptance, and completion.
- If no task source is declared, keep the current user task as working context; never nominate a workspace artifact merely because it exists.
- Keep accepted rationale, decisions, and durable project truth with their established owners. The task source may link to that truth but must not replace or duplicate it.
- Separate candidate ideas from accepted direction, then make dependencies and verification visible.
- Never create, update, or mirror an external tracker without authority.
