# Task Coordination

Coordinate related tasks, assign responsibilities, manage dependencies, and verify combined results. Use the workspace's available people, agents, and tools.

The stable package ID is `orchestration`.

## What You Get

[Managed Delivery](content/.agents/skills/use-workflow/references/orchestration/managed-delivery.md) is a workflow for planning dependencies, assigning bounded work, preserving interrupted work, and checking authorized integration.

**Direct dependencies:** [Development](../development/README.md), [Observations and Handoffs](../observations-and-handoffs/README.md), [Planning](../planning/README.md).

Planning and Development supply the methods Managed Delivery calls. Observations and Handoffs supplies independently useful record categories and starters. Workflow Support is installed once through the method dependencies.

## Start Using It

> Use Managed Delivery for these related tasks. Keep responsibilities clear, work sequentially unless concurrency is justified, and verify the combined result.

One person or agent can perform every responsibility. The package installs no fixed model roster, hierarchy, scheduler, or tool permissions. Parallel changes require appropriate authority and safely isolated responsibilities. Installation grants no permission to commit, integrate, publish, or contact external systems.

Choose [Observations and Handoffs](../observations-and-handoffs/README.md) alone when you only need those records. Task Coordination does not install Project Documents or Flows and Scenarios, and remains outside Development Toolkit.
