# Review Experience Design

## Criteria

- Trace the intended journey and state transitions before evaluating local presentation choices.
- Check discoverability, hierarchy, comprehension, feedback, control, efficiency, accessibility, consistency, error prevention, recovery, and trust.
- Tie each finding to user impact, evidence, severity, and the smallest useful correction. Preserve strengths that a revision should not lose.
- Separate confirmed defects, preference, missing context, feasibility risk, and questions that need validation.
- Recommend accept, revise, or validate. State the evidence needed for every unresolved question that could change the result.

## Result

The review supports an evidence-based design decision rather than a list of preferences.
