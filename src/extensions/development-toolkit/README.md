# Development Toolkit

One selection for current project knowledge, planning, and development. This package contains no runtime files of its own.

## Included Packages

| Package | Contribution |
| --- | --- |
| [Project Documents](../project-documents/README.md) | Current document convention, five starters, Vision, and Architecture |
| [Planning](../planning/README.md) | Ideas, Analysis, Decisions, work records, eleven starters, and Planning |
| [Development](../development/README.md) | Development, Debugging, and Review |

Each uses [Workflow Support](../workflows/README.md), installed once through dependency resolution.

## Deliberately Separate

[Orchestration](../orchestration/README.md) adds Managed Delivery, Observations, and the Observation and Handoff starters. Select it separately when coordination and execution learning help. The Toolkit does not install those files implicitly.

Install individual packages instead when only part of the starter set is useful. A bundle selects capabilities; it does not require every convention or make their use mandatory.

See the [installation guide](../../../docs/extensions.md).
