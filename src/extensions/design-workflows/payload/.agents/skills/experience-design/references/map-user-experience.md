# Map User Experience

## Capability

- Establish target users, job, evidence, constraints, and success signal.
- Map the primary journey plus applicable entry, empty, loading, success, error, interruption, permission, and recovery states.
- Compare distinct directions by comprehension, effort, feedback, control, accessibility, consistency, feasibility, and risk.
- Recommend from evidence or define the smallest resolving prototype, research question, or decision.

## Expected Result

Experience directions address the full user journey without candidates becoming accidental requirements.
