# Design Workflows

Optional Open Forge workflows for exploring user experience directions, reviewing a design, and preparing an implementation-ready handoff.

It installs:

- UX exploration, design-review, and implementation-handoff workflow routes
- the lean `experience-design` skill and its focused references

These routes keep candidate design decisions distinct from accepted decisions and keep implementation outside the handoff workflow.

Install it with:

```sh
open-forge extend design-workflows
```

The installed payload files remain runtime truth. The manifest is install-time metadata only.
