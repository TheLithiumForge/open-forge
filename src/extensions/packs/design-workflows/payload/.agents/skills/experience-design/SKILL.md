# Experience Design

Carry user intent from problem evidence through an implementation-ready experience.

## Process

- Start from users, jobs, evidence, constraints, and success signals rather than screens alone.
- Cover journeys, transitions, edge states, accessibility, content, consistency, feasibility, and recovery.
- Keep observations, inferences, candidates, accepted decisions, and implementation discretion distinct.
- Match artifact fidelity to the decision and never invent missing design truth.
