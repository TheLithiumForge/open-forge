# Design Tests

## Capability

- Declare whether the task runs existing tests or checks, authors new ones, or does both.
- Cover stable behavior or outcomes, contracts, edge cases, invalid inputs, state transitions, regressions, and integration seams proportionately.
- Investigate whether a failure belongs to product behavior, test expectation, setup, environment, or unrelated state.
- Never weaken a valid assertion merely to pass.

## Expected Result

Test or check evidence supports a defensible conclusion and exposes its coverage limits.
