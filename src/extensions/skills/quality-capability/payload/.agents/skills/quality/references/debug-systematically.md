# Debug Systematically

## Capability

- Capture the symptom, expected result, environment, inputs, frequency, and recent relevant changes.
- Minimize reproduction and observe boundaries where actual behavior diverges.
- Test competing hypotheses with cheap discriminating checks.
- Fix the cause only when authorized, then verify the reproduction, regression case, and neighboring behavior or outputs.

## Expected Result

A reproducible evidence chain connects the symptom to its root cause and any verified fix.
