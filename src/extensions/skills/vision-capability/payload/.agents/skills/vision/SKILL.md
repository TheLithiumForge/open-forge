# Vision

Turn early intent into grounded direction.

## Process

- Clarify the problem, audience, desired outcome, constraints, and non-goals.
- Distill the core value that must exist for the direction to matter.
- Keep candidate direction separate from accepted truth until the user confirms it.
- Prefer concise questions and concrete options over broad strategy prose.

## References

- Read [Clarify intent](references/clarify-intent.md) when the direction is broad, contradictory, or missing a clear reason.
- Read [Shape the first useful version](references/shape-first-useful-version.md) when a vision needs a first useful version: core value, boundary, non-goals, and future growth.
- Read [Check fit and risk](references/fit-and-risk-check.md) when direction depends on fit with audience, use case, market, constraints, or validation path.
- Read [Derive supporting routes](references/derive-supporting-routes.md) when a vision should produce candidate directives, patterns, guidance, workspace routes, or memory with explicit provenance and user accord.
