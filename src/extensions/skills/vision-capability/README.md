# Vision Skill

Skill-only extension providing the `vision` skill for product, project, feature, service, process, or workspace direction. It includes first-useful-version shaping, fit and risk checks, growth directions, and provenance-aware derivation of supporting routes that are promoted only with user accord.

It is installed automatically by `vision-workflow` and may be selected directly when only the skill is wanted:

```sh
open-forge extend vision-capability
```

The installed `SKILL.md` package remains runtime truth. The manifest only composes installation.
