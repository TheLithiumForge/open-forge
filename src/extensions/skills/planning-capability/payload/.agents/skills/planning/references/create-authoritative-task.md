# Create Authoritative Task

## Capability

- Name the one user- or workspace-declared authoritative task source before changing task state. Default to the current user task when none is declared. Never promote an artifact merely because it exists.
- Check that source for an existing owner of the outcome before creating anything.
- Include outcome, rationale link, scope, non-goals, ownership, dependencies, acceptance evidence, and starting context.
- Keep task status, ownership, acceptance, and completion in that source. Route accepted rationale, decisions, and durable project truth to their established owners, then link to them from the task when useful.
- Without mutation authority, return a proposal for the declared source. Never mirror it elsewhere.

## Expected Result

One task or proposal owns the work without introducing duplicate task truth.
