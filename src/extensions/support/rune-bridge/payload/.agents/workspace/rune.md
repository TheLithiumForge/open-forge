# Rune

Rune may assist relevance and recall when the current workspace or runtime provides an integration.

## Destinations

- [authoritative Open Forge instructions, routes, memory, and indexes; read these files directly when deterministic routing or exact truth matters.](../) - #Core #Routing

The workspace's installed Rune integration and its own documentation remain the authority for whether Rune is available and how its current interface behaves.

## Use When

- Confirm Rune availability from the user, workspace, or runtime before relying on it.
- Use Rune-assisted recall to narrow a broad search or surface potentially relevant context when its installed documentation supports that use.
- Use Open Forge entrypoints, tags, paths, Required Routes, and direct file reads for deterministic routing, mandatory instructions, and verification.
- Treat any Rune-derived index or recall result as rebuildable relevance data that points back to authoritative workspace files.
- Fall back to Open Forge routing and ordinary workspace search whenever Rune is absent, uncertain, stale, or insufficiently precise.

This route intentionally defines no Rune command, configuration file, storage layout, or installation procedure.
