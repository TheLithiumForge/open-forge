# Documents

## What is the complete current explanation of this subject?

A Document presents accepted current knowledge as one coherent view.

## Axioms

- Check `Entries` when the work needs accepted current knowledge.
- Explain the subject so readers can use it without piecing its current meaning together from Decisions. Link to a Decision when its reasoning helps.
- When a Document names another source as authoritative, follow that source for the detail it defines rather than duplicating it. Linking to it does not make its content accepted.
- Keep Documents top-down. Top-level Documents give an overview of the whole and summarize each narrower Document they link to. Each narrower Document explains its own part in more detail and links back up.
- When accepted knowledge changes a narrower Document, also update the summaries above it that no longer match.
