# Rune Bridge

Optional route-only context for workspaces that use Rune alongside Open Forge.

It installs:

- a workspace route describing the boundary between Open Forge truth and optional Rune-assisted relevance
- guidance for choosing Rune-assisted recall or deterministic Open Forge routing

This pack does not install Rune, define a Rune command or configuration contract, or add a directive. Agents must confirm that Rune is available and follow the integration's own current documentation.

Install it with:

```sh
open-forge extend rune-bridge
```

Open Forge Markdown files remain authoritative. Any derived Rune index is a rebuildable aid, not a second source of truth.
