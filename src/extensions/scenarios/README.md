# Flows And Scenarios

Describe the experience you want people to have, then keep an honest record of what happens when it is tried. These starters fit planning, exploration, and verification.

## What You Get

| Starter | Use it to |
| --- | --- |
| [User Flow](content/.agents/templates/scenarios/user-flow.md) | Connect scenarios from a starting state to a meaningful goal. |
| [Scenario](content/.agents/templates/scenarios/scenario.md) | Describe one situation, the actions taken, and the expected outcome. |
| [Scenario Collection](content/.agents/templates/scenarios/scenario-collection.md) | Group related cases without duplicating their expectations. |
| [Run Record](content/.agents/templates/scenarios/run-record.md) | Record actual actions, observations, checks, and follow-up. |

**Direct dependencies:** None.

## Start Using It

> Describe the expected experience as a flow with scenarios. After trying it, record the actual result separately.

A Scenario can plan something that does not exist yet. A Run Record describes an actual attempt. Neither establishes acceptance by itself. Keep expected and observed results separate, and connect flow steps through the state actually left by preceding steps.

Use these records for products, services, or other work. They do not require an executable plan, a task tracker, a software test runner, or the Planning Extension.
