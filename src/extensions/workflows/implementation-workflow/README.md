# Implementation Workflow

Workflow-only extension for implementing and verifying code, configuration, documentation, design assets, or another concrete work product.

Choose this for a focused implementation pass. Choose `testing-workflow` when evidence is the whole task, or `dev-workflow` when the change warrants repeated implementation, improvement, retest, diagnosis, and fixes.

It depends on `implementation-capability`. The selector marks that skill extension as required automatically.

```sh
open-forge extend implementation-workflow
```
