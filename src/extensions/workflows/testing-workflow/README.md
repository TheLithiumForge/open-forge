# Testing Workflow

Workflow-only extension for running existing checks, authoring new evidence, or doing both without weakening valid expectations.

Choose this when evidence is the deliverable and product implementation is outside scope. Choose `implementation-workflow` for one focused change, or `dev-workflow` for the full iterative delivery cycle.

It depends on `quality-capability`; the selector marks that skill extension as required automatically.

```sh
open-forge extend testing-workflow
```
