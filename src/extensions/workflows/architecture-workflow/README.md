# Architecture Workflow

Workflow-only extension for mapping and changing the structure of a technical, product, operational, or organizational system. It handles greenfield, unstructured/rescue, and established starting states. It defines a minimal first and likely second vertical slice. It derives only the supporting directives, patterns, guidance, workspace truth, decisions, and operational material the direction warrants.

Every deduced candidate carries user-stated, observed, or inferred provenance. Normative Core or CurrentTruth material is created only with user accord. Useful unaccepted deductions stay emerging or are returned as proposed routes.

It depends on `architecture-capability`. The selector marks that skill extension as required automatically.

```sh
open-forge extend architecture-workflow
```
