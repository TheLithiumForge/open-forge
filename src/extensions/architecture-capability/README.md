# Architecture Capability

Skill-only extension providing the native `architecture` skill for technical, product, operational, and organizational system work. Its references cover greenfield bootstrap, current-system mapping, option comparison, decision framing, migration slicing, and deriving appropriately scoped supporting routes with provenance and user accord.

It is installed automatically by `architecture-workflow` and may be selected directly when only the skill is wanted:

```sh
open-forge extend architecture-capability
```

The installed `SKILL.md` package remains runtime truth; the manifest only composes installation.
