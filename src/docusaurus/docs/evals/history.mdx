# History
Eval History is a page that shows saved results across CLI versions and grading versions, with the reference solution kept apart.

For example, after rewording the Framework, compare check coverage on the same starting point, model and grading before and after that CLI version. Different grading versions get separate charts, so a changed grader can't look like a better implementation.

A coverage interval entirely below the earlier interval is a screening regression. Other comparisons are inconclusive, and small screening samples don't show a benefit. Every CLI is still beta, and nothing here is a claim yet.
