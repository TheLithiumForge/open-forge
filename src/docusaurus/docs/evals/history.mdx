# History
Eval History is a browser that shows saved results across CLI versions and grading versions, with the reference data point kept apart.

For example, after rewording the Framework, compare coverage on the same layer, models and grading before and after that CLI version. Different grading versions get separate charts so a changed grader can't look like an improved implementation.

A coverage interval entirely below the earlier interval is a screening regression. Other comparisons are inconclusive. Small screening samples don't establish a benefit. Every CLI stays beta. Nothing is a claim yet. The data commit, copy or fetch time and analysis version apply to every chart below.
