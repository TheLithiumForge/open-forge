# Results
Eval Results is a page that compares how AI coding agents build the same game under different setups, with and without Open Forge.

Every run starts from one of four starting points, from a one-line idea to an existing app. Each setup is compared with a control on the same starting point and model. The [Evals overview](index.md) explains how runs are made and graded.
