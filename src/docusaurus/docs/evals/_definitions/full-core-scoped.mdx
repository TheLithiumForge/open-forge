This is the one deliberately improper use of Open Forge. The project gets the Full Core install, but every document stays outside its categories, in topic folders under an outside `docs/` route. The rule, advice, map and pattern catalogues stay empty, and Memory holds no records.

Each folder has an entrypoint, so an agent can pick a topic, but rules stay inside prose pages, and reaching them means reading those pages. Compare it with [Full Core, proper](#full-core-proper), which holds the same facts in the categories. Results from before this rename called it Full Core, scoped.
