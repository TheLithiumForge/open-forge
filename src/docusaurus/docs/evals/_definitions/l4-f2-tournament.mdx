`l4-f2-tournament`, "Tournament mode", is a large feature case that tests documentation at a size no agent can read in one go. The request asks for a knockout tournament for 4 or 8 players on one device, and gives every label a person sees, so Code only can build it too.

The project brings about 300,000 tokens of documents, with 30 project rules planted one per document. Most of them never mention tournaments, so searching for the feature misses them. Twelve core checks need only the request. Thirty rule checks need the documents, and their coverage is the case's main measure.
