The agent gets the existing app's code, tests and README with the change request. The project has no spec documents, the README has no line that points to `docs/` and the prompt is the request alone.

Only an existing app uses Code only. It's a delivery variant, not a rung on the [setup ladder](../../demos/index.md#setup-ladder). It shows what the spec documents add, so compare it with Plain docs and not with the Open Forge setups, which all have the documents.
