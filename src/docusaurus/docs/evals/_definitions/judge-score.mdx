Judge score is the share of yes ballots among all of a judge's ballots for a run. A judge is a model that reads the run's source code and screenshots, then answers fixed questions with yes, no or unsure, citing files, lines or images. It casts three ballots per question. Unsure ballots count in the total, so they lower the score like a no.

The questions cover the code, the look and rules from the task, such as keeping each component's logic, markup and styles together. An existing app currently uses the idea's questions.
