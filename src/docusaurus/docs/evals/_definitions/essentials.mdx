The project gets a fresh Open Forge install with the Essentials preset: everything in Minimal plus Patterns, Skills, Emerging Memory and Working Memory, with Working records kept out of Git. From a short brief on, the documents are routed the same way as in Minimal.

Essentials is rung 4 of the [setup ladder](../../demos/index.md#setup-ladder). [Installation](../../getting-started/installation.md#choose-the-installed-routes) describes what each preset installs.
