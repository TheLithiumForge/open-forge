The project gets everything in Organized docs, plus a root `AGENTS.md` that says to follow the requirements in `docs/` and links every document with a one-line description. The descriptions are the same ones the Open Forge setups give each document. A `CLAUDE.md` that imports `AGENTS.md` gives Claude Code the same start, as the Open Forge setups do. Batches started on or before 2026-11-02 wrote `AGENTS.md` only.

Linked AGENTS.md is rung 2 of the [setup ladder](../../demos/index.md#setup-ladder).
