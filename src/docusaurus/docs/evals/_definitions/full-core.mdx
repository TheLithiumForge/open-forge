The project gets a fresh Open Forge install with the Full Core preset: every built-in category and Memory state. That adds Guidance, Maps, Templates and Archived Memory to Essentials, and Install keeps nothing out of Git. From a short brief on, the documents are routed the same way as in Minimal.

Full Core is rung 5 of the [setup ladder](../../demos/index.md#setup-ladder). [Installation](../../getting-started/installation.md#choose-the-installed-routes) describes what each preset installs.
