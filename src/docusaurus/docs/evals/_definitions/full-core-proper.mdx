The project gets the Full Core install, with every document placed in the category that fits it, in topic scopes with their own entrypoints. Rules go to Directives, current explanations and decisions to Crystallized memory, advice to Guidance, document lists to Maps, history to Archived and open research to Emerging. Nothing sits in an outside `docs/` folder.

Rules that apply to all source work load by themselves for that work, rules for tests load for test work, and each feature area's rules stay on demand, for the task to select by description. Every other document opens on demand.

A reader that couldn't see which rules are graded chose which sentences count as rules. Each one moves word for word into a rule file, and its page links to it, so every setup holds the same facts.
