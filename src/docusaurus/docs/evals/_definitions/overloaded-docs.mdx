The project holds Organized docs plus the notes a real project collects, mixed into the same `docs/` folder: four decisions, three analyses, four ideas that were rejected or parked, and four tryouts and spikes that worked or didn't. The notes add no requirement and reveal no defect, so an agent has to tell the spec from the history around it.

Overloaded docs pairs with [Full Core, scoped, with memory](#full-core-scoped-memory), which carries the same notes on Open Forge Memory routes.
