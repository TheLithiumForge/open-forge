Check coverage is the share of a run's applicable checks that pass. Checks are automated tests of the built game, run after the agent stops, and most of them play the game in a browser. A short brief adds static and build checks, and a full spec adds replay checks too. An existing app runs its change checks, the full spec's checks again as regression checks and two guards.

A check blocked by an earlier failure counts as not passed. Each starting point has its own check set, so compare coverage within one starting point.
