The project gets [Full Core, scoped](#full-core-scoped) plus the Planning and Observations Extensions, with the same notes as [Overloaded docs](#overloaded-docs) on their Memory routes. Decisions sit in Crystallized Memory as accepted knowledge. Analyses, ideas and tryouts sit in Emerging Memory as candidates, so a rejected idea never reads as a rule. Each note carries its description, and `open-forge index` lists it in its route's catalogue.
