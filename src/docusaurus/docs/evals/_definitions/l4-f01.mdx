`l4-f01`, "Name a saved deal", is a feature case. The request asks for a name you can give a game before you save it, so the name comes back when you load the saved progress. The spec gets a matching update to version 3. A named game saves as snapshot version 2, while unnamed games, board codes and replay output keep version 1.

Ten checks cover the new name, including naming and exporting a game, input length limits, clearing a name, editing paused and completed games, reloading the page and rejecting invalid saves.
