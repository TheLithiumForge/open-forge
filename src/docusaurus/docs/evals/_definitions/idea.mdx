The agent gets one short prompt in an empty project. The prompt asks for a neon memory game with grid sizes from 4x4 to 16x16, card faces drawn by code, a move counter, a New Game button and a best score for each size. The game has to work on a phone and with a keyboard. It uses React and TypeScript and builds to one `index.html` file you can open. The prompt also asks the agent to keep each component's logic, markup and styles together.

Everything else is the agent's choice, or a question. The simulated user knows five private preferences, such as the starting grid size and the colors, and gives one only when the agent asks about it. Checks test only what the prompt asks for.
