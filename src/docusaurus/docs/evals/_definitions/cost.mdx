Cost is what a run's tokens would cost on the provider's API, in US dollars, at the [current prices](../prices.mdx). It prices new input, cached input, cache writes and output separately, and each thread at its own model's prices, so a run led by one model with subagents on another adds up correctly.

Use cost to compare different models, or a large model leading smaller ones, where token counts mislead. A cheap model's million tokens cost a fraction of a large model's. It's an API price, not what the run was billed, since these runs use subscriptions.
