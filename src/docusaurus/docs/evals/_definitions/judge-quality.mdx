Judge quality says how good the work is, as a share of full marks. Judges score seven dimensions out of 10, against written descriptions of what 2, 5 and 8 look like. Four cover how the game plays: handing the device over, understanding results, keyboard and screen reader use, and finish. Three cover the code: ownership of state, ease of change and the trust boundary for loaded files. Play and code weigh the same.

Each judge casts three ballots, and a dimension takes the middle one. Judges read the source and a scripted playthrough of the built game, which every run gets the same way, and never see the docs or know which setup made the run.
