The project gets a fresh Open Forge install with the Minimal preset: the loader, Directives, Crystallized Memory, the guide for people and the Open Forge sections in `AGENTS.md` and `CLAUDE.md`. From a short brief on, the documents sit in `docs/` as in Plain docs, with a description and tags in each one's frontmatter. The loader lists the `docs/` catalogue with the `LoadNow` tag, so the agent reads the list of documents at startup.

Minimal is rung 3 of the [setup ladder](../../demos/index.md#setup-ladder). [Installation](../../getting-started/installation.md#choose-the-installed-routes) describes what each preset installs.
