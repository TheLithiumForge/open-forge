The project gets a fresh Open Forge install with the Minimal preset: the loader, Directives, Crystallized Memory, the guide for people and the Open Forge sections in `AGENTS.md` and `CLAUDE.md`. From a short brief on, the documents sit in `docs/` as in Plain docs, with a description and tags in each one's frontmatter. The loader lists the `docs/` catalogue with the `LoadNow` tag, and every document except the acceptance examples carries that tag too, so the agent reads almost the whole spec at startup. [Full Core, scoped](../setups.mdx#full-core-scoped) loads only the overview.

Minimal is rung 3 of the [setup ladder](../../demos/index.md#setup-ladder). [Installation](../../getting-started/installation.md#choose-the-installed-routes) describes what each preset installs.
