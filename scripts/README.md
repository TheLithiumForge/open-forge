# Repository scripts

Start with [forge](delivery/README.md) for setup, builds, tests, packaging,
versioning and publication. Run it from the repository root:

```sh
npx forge --help
```

| Directory                                | Purpose                                                                          |
| ---------------------------------------- | -------------------------------------------------------------------------------- |
| [delivery](delivery/README.md)           | Shared local and CI delivery commands, the npm launcher and release preparation. |
| [agent-tooling](agent-tooling/README.md) | Repository-owned agent projections and review tools.                             |

The [development guide](../docs/development.md) covers the .NET workspace,
platform prerequisites and contributor workflows.
